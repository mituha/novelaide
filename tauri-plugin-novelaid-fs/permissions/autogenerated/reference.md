## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-ping`
- `allow-get-document-type`
- `allow-get-directory-type`
- `allow-read-directory`
- `allow-set-project-directory`
- `allow-get-project-directory`
- `allow-read-document`
- `allow-write-document`
- `allow-create-directory`
- `allow-create-file`
- `allow-create-next-file`
- `allow-remove`
- `allow-rename`
- `allow-copy`
- `allow-get-metadata-cache`
- `allow-scan-project-metadata`
- `allow-scan-documents`
