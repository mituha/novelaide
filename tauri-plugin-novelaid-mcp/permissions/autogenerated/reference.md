## Default Permission

Default permissions for novelaid-mcp plugin

#### This default permission set includes the following:

- `allow-get-mcp-status`
- `allow-start-mcp-server`
- `allow-stop-mcp-server`
- `allow-respond-tool-call`
- `allow-update-mcp-config`
