## Default Permission

Default permissions for restar-git plugin

#### This default permission set includes the following:

- `allow-git-is-repo`
- `allow-git-init`
- `allow-git-status`
- `allow-git-stage`
- `allow-git-unstage`
- `allow-git-commit`
- `allow-git-log`
- `allow-git-diff-file`
- `allow-git-discard`
- `allow-git-get-remotes`
- `allow-git-push`
