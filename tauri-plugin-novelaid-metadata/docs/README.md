# tauri-plugin-novelaid-metadata ドキュメント一覧

本ディレクトリでは、小説メタデータおよび作品知識ハブプラグイン（`tauri-plugin-novelaid-metadata`）のアーキテクチャ設計および機能仕様書をまとめています。

---

## 📖 仕様書一覧

* **[統合メタデータプラグイン仕様](./統合メタデータプラグイン仕様.md)**
  - 物理ファイルI/Oから独立した作品知識プロセッサ、エンティティ・リレーション解決の全体仕様。
* **[メタデータおよびインデックス自動生成仕様](./メタデータおよびインデックス自動生成仕様.md)**
  - プロジェクト内全ドキュメントの非同期スキャン、Frontmatter解析、登場人物・地名・用語の自動抽出仕様。
* **[メタデータ編集パネル実装仕様](./メタデータ編集パネル実装仕様.md)**
  - 単一ドキュメントのFrontmatterメタデータ（コア項目・タグ・エンティティ詳細）編集UI実装仕様。
* **[メタデータリストパネル実装仕様](./メタデータリストパネル実装仕様.md)**
  - 登場人物・地名・プロットなどカテゴリ別一覧表示、階層フィルタリング、ドラッグ＆ドロップ連携UI実装仕様。
