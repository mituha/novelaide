### 実施作業・設計判断
1. **【旧Electron版 `novelaid-editor` の実装調査】**:
   - `src/renderer/components/TabBar/TabBar.tsx` および `TabBar.css` を調査。
   - 通常マウスホイールイベントの `deltaY` を `scrollLeft` にマッピングする横スクロール手法、および左端の `ChevronDown` による「開いているタブ一覧」ポップオーバーメニューの実装を確認。
2. **【Flexboxレイアウトの突き破り防止】**:
   - `src/components/Editor/EditorTabs.css`: `.editor-tabs-bar` に `min-width: 0`、`.editor-tabs-list` に `min-width: 0; flex: 1;`、`.editor-tabs-actions` に `flex-shrink: 0; margin-left: auto;` を設定。
   - タブが多数開いても右端の重要アクション（編集/閲覧切替、分割、プレビュー等）が絶対に押し出されず固定されるように保護。
3. **【マウスホイールでの水平スクロール実装】**:
   - `src/components/Editor/EditorTabs.tsx`: `handleWheel` を実装し、Shiftキー不要で上下ホイール操作を水平スクロールに変換（トラックパッドの横ジェスチャーにも対応）。
   - CSS で `scrollbar-width: none` および `::-webkit-scrollbar { display: none; }` を適用し、スクロールバーを隠してすっきりとしたモダンUIを実現。
4. **【アクティブタブの自動スクロールイン（`scrollIntoView`）】**:
   - `src/components/Editor/EditorTabs.tsx`: `activePath` の変更を監視し、画面外にあるアクティブタブを `scrollIntoView({ behavior: 'smooth', block: 'nearest', inline: 'nearest' })` で可視範囲へスムーズに引き込むフックを追加。
5. **【開いているタブ一覧ドロップダウンメニューの新設】**:
   - `src/components/Editor/EditorTabs.tsx`: タブバー左端に `ChevronDown` ボタンを新設。
