- **一括拡張子変更における確認ダイアログ先行実行（WebView同期ズレ）の解消**:
  1. **原因の究明**:
     - `BatchExtensionChanger.tsx` で同期的な Web 標準の `window.confirm()` を使用していた。
     - Tauri の WebView2（デスクトップ環境）において同期ダイアログを呼び出すと、WebView のメッセージループと JavaScript 実行スレッドの同期順序が狂い、ダイアログのレンダリングより先に後続の非同期処理やファイル書き込みが裏で先行実行されてしまう問題（以前のファイル削除時と同様の事象）が発生していた。
  2. **Tauri ネイティブモーダルダイアログ（`confirmDialog`）への移行**:
