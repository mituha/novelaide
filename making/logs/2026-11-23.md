### 作業内容
- **プロジェクト切替およびアプリ終了時におけるプロジェクトクローズ＆ドキュメント保存・破棄ライフサイクルの実装**:
  1. **原因の究明**:
     - `ProjectContext.openProject` で新しいプロジェクトを開く際、既存プロジェクトのクローズ処理（`closeProject`）が呼び出されておらず、`DocumentContext` 内の `useEffect` による非同期クリーンアップと新プロジェクト自動復元フックが競合してドキュメントタブが残存していた。
     - また、アプリ終了時（ウィンドウの「×」ボタン押下）における未保存ドキュメントの安全な保存やプロジェクトクローズ処理（Tauri `onCloseRequested` / `beforeunload`）が未実装だった。
  2. **`ProjectContext` の強化 (`src/contexts/ProjectContext.tsx`)**:
     - `closeProject` を非同期関数化し、登録されたクローズハンドラ（`closeHandlerRef`）を実行するように改修。
     - `openProject` 呼び出し時、既存プロジェクトが開かれている場合は事前に `await closeProject()` を実行して前プロジェクトを完全に閉じてから新プロジェクトを開く直列フローを構築。
     - 外部コンテキストからクローズ処理をフックできる `registerCloseHandler` を公開。
  3. **`DocumentContext` の状態管理堅牢化 (`src/contexts/DocumentContext.tsx`)**:
     - `closeAllDocuments(options?: { saveDirty?: boolean })` を実装・公開。未保存のドキュメントがあればすべて安全にファイル保存した上で、タブ状態（`openDocuments`）、ペインのアクティブパス、スプリット状態を初期化。
     - `registerCloseHandler` を通じて `closeAllDocuments({ saveDirty: true })` を `ProjectContext` に登録。
     - `currentProjectPath` 変更検知時の `openDocumentsRef.current = []` および `autoRestoredProjectRef.current = null` を同期化し、新プロジェクトの直近編集ファイル（`autoRestoreLastNovel`）が確実に復元されるよう制御。
  4. **アプリ終了フックの導入 (`src/hooks/useWindowCloseHandler.ts` & `src/App.tsx`)**:
     - Tauri 2.x の `@tauri-apps/api/window` から `getCurrentWindow().onCloseRequested` をフック。
     - ウィンドウ終了要求時に即時破棄を抑止（`event.preventDefault()`）し、未保存ドキュメントの自動保存と `closeProject()` を完了させた後で安全にウィンドウを破棄（`destroy()`）して終了するライフサイクルを実装。
     - Web環境・リロード対策として `beforeunload` も併設。
  5. **ドキュメント・仕様書の同期**:
     - `docs/dev/プロジェクト選択および管理仕様.md`: プロジェクト切替時の事前クローズ、`closeProject`、`registerCloseHandler`、および `useWindowCloseHandler` のライフサイクル仕様を追記。
     - `docs/manual/プロジェクトの選択と新規作成.md`: プロジェクト切替時の自動保存・前作品タブ破棄、アプリ終了時の安全保存について追記。
  6. **バージョン更新**:
     - `npm version minor --no-git-tag-version` を実行し、`v0.67.2` から **`v0.68.0`** へ更新。
