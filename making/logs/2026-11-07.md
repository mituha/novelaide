> 3点リーダー、ダッシュの補完が表示されません。text補完が無効化されていませんか？

### 実施作業・設計判断
1. **【Text補完無効化の要因特定と解消】**:
   - `CodeEditor.tsx` において `suggest: { showWords: !isWritingMode }` と設定されていたため、VS Code / Monaco の内部実装で `CompletionItemKind.Text`（三点リーダー、ダッシュ、閉じ括弧等）が `showWords: false` により非表示フィルターに落とされていた不具合を特定。
   - すでに `wordBasedSuggestions: 'off'` によりファイル内英単語の自動収集ノイズは停止されているため、`suggest.showWords: true` に修正して明示的に呼び出された `CompletionItemKind.Text` を確実に表示可能に修正。
2. **【補完アイテムのマッチングと入力範囲の最適化】**:
   - `src/components/Editor/EditorSupport.ts`:
     - `model.getWordUntilPosition(position)` を用いた標準的な `range` 設定を導入。
     - 三点リーダー（`filterText: '……...さんてんリーダー'`）、ダッシュ（`filterText: '――--ダッシュだっしゅ'`）、ルビ（`filterText: '｜漢字《かんじ》るびルビruby'`）、傍点（`filterText: '《《傍点》》ぼうてんきょうちょう'`）を設定し、部分入力や読み仮名からの `Ctrl + Space` トリガーでも確実にヒットするよう補完精度を大幅に向上。
3. **【ビルド検証とバージョン更新】**:
