# 第38回：複数タブの水平スクロールとクイックピッカーの実装

こんにちは！ 小説執筆用エディター『**novelaide**』の開発チームです。

今回は、小説の長編執筆や設定資料・プロットなどを次々に開いていくと必ず直面する、**「タブが多すぎて画面外に隠れてしまう問題」**の解決と、最新エディタのトレンドを取り入れた快適なタブUIの実装についてお届けします。

---

## 1. 課題：タブが増えるとボタンが画面外に押し出される？

長編小説の執筆現場では、「プロローグ」「第1話」「第2話」「登場人物設定」「プロットメモ」「用語集」など、一度に何十ものファイルを行き来しながら作業することが日常茶飯事です。

しかし、従来のタブバーでは以下の問題が発生していました：

1. **Flexboxの突き破り（アクションボタンの消失）**:
   - タブの合計幅が表示領域を超えると、Flexboxのデフォルトの挙動によってタブリストがコンテナを突き破り、右端にある「編集/閲覧切替」「横に分割」「分割プレビュー」といった重要なアクションボタンが画面外に押し出されて消えてしまう。
2. **横スクロールバーの操作性の悪さ**:
   - 画面下に3pxの極小スクロールバーが出ていたものの、マウスでドラッグしづらく、直感的に左右へ移動できない。
3. **アクティブタブがどこにあるか見失う**:
   - エクスプローラーから離れた話数を開いたり、エピソード前後ナビゲーションで移動した際、画面外のタブが選択されてもスクロールが追従せず、どのファイルを開いているのか見えなくなってしまう。
4. **大量タブから探すのが大変**:
   - 20個も30個もタブがあると、目的のファイルを探すために端から端までスクロールする必要がある。

旧Electron版（`novelaid-editor`）では、マウスホイールで横スクロールできたり、タブ一覧ドロップダウンが用意されていました。
そこで、この実績ある良さを継承しつつ、VS Code等で親しまれている最新のタブUX（自動スクロールイン、スマートなレイアウト保護）を組み合わせた**「新時代のタブ操作基盤」**を構築することにしました。

---

## 2. 設計：堅牢な3分割Flexboxレイアウト

まず最初に行ったのは、CSS Flexboxの根本的なレイアウト見直しです。

```text
+-----------------------------------------------------------------------------------------+
| [v] | [Tab 1] [Tab 2] ... [Tab N] (水平スクロール可能)       | [表示] [横に分割] [分割プレビュー] |
+-----------------------------------------------------------------------------------------+
 (1)        (2) tabsListRef / flex: 1, min-width: 0                 (3) flex-shrink: 0, margin-left: auto
```

* **(1) ドロップダウンボタン（左端）**: `flex-shrink: 0` で幅固定。
* **(2) スクロールタブ領域（中央）**: `flex: 1; min-width: 0;`。`min-width: 0` を指定することで、子要素（タブ）がいくら増えても親の幅を超えて広がらないよう強制します。
* **(3) アクションボタン群（右端）**: `flex-shrink: 0; margin-left: auto;`。これにより、タブがどれだけ増殖しても、右端のボタン群は絶対に押し出されず、右端にしっかりと固定されます。

また、各タブ（`.editor-tab-item`）には `flex-shrink: 0; min-width: 100px; max-width: 200px;` を設定し、タブが増えても文字やアイコンが無理に押し潰されないようにしました。

## 3. 実装：快適なスクロールとクイックピッカー

### ① 通常マウスホイールによる水平スクロール
一般的なマウスには横スクロールホイール（チルト）が付いていないことが多いため、**通常の縦ホイール操作（`deltaY`）を水平スクロール（`scrollLeft`）に変換**するハンドラを実装しました。

```typescript
const handleWheel = (e: React.WheelEvent<HTMLDivElement>) => {
  if (tabsListRef.current) {
    const delta = Math.abs(e.deltaX) > Math.abs(e.deltaY) ? e.deltaX : e.deltaY;
    if (delta !== 0) {
      tabsListRef.current.scrollLeft += delta;
    }
  }
};
```
これにより、タブバーの上にカーソルを置いてホイールを上下に回すだけで、タブが左右へスーッと滑らかにスクロールします（トラックパッドの横スワイプにも自然に対応します）。
見た目の野暮ったいスクロールバーは `scrollbar-width: none;` で非表示にしています。

### ② アクティブタブの自動スクロールイン（Auto Scroll Into View）
ファイルツリーや検索結果、フッターのエピソード移動などで、現在スクロール外に隠れているファイルがアクティブになった際、タブバーが自動でスライドして該当タブを画面内に連れてくる処理を追加しました。

```typescript
useEffect(() => {
  if (!activePath || !tabsListRef.current) return;
  const activeElem = tabsListRef.current.querySelector<HTMLElement>('.editor-tab-item.active');
  if (activeElem) {
    activeElem.scrollIntoView({
      behavior: 'smooth',
      block: 'nearest',
      inline: 'nearest',
    });
  }
}, [activePath]);
```

### ③ 開いているタブ一覧クイックピッカー（`ChevronDown` メニュー）
タブバーの左端に、下矢印アイコン（`ChevronDown`）のボタントリガーを新設しました。

クリックすると、現在開いている全タブが縦並びリストでポップオーバー表示されます：
* ファイル種別アイコン（小説、Markdown等）
* ファイルタイトル（未保存時は赤色文字）
* 未保存インジケーター（赤丸 `●`）
* 個別閉じるボタン（`×`）

目的のファイルをクリックすれば瞬時にそのタブへ切り替わり、ドロップダウンが自動で閉じます。外側をクリックした際もスマートにクローズします。

## 4. 実際の使い心地

1. **タブを15個開いてもレイアウトが崩れない！**:
   - 右端の「分割」や「プレビュー」ボタンが常に所定の位置にあり、安心して作業できます。
2. **ホイールをクルクル回すだけでタブを探せる**:
   - Shiftキーなどを押す必要もなく、タブバー上でホイールを回すだけで軽快に左右移動できます。
3. **エピソード移動しても迷子にならない**:
   - 前後のエピソードへ移動すると、アクティブタブがふわっと中央付近に自動スクロールしてくれます。
4. **大量タブはドロップダウンから一発ジャンプ**:
   - 開きすぎたタブも、左端のメニューからリスト形式でサッと見つけて切り替えられます。
