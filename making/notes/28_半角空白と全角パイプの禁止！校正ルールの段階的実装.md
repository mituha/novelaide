## 1. なぜ小説で「半角空白」と「全角パイプ」を禁止するのか？

日本語の小説原稿では、一般的なビジネス文書やプログラミング用コードとは異なる、独自の組版・出版作法が存在します。

### ① 半角空白（` `）の禁止
* **小説作法**: 日本語の小説では、段落冒頭の「字下げ」や感嘆符・疑問符（！？）直後のアキなど、空白を空ける場面では**すべて全角空白（`　`）を使用する**のが鉄則です。
* **混入の課題**: PCやスマホでの入力時、無意識に半角スペースキーを押してしまったり、Webからのコピペ原稿に半角スペースが混ざっていたりすると、電子書籍リーダーや原稿用紙換算、縦書きプレビューで表示が崩れる原因になります。
* **解決策**: 小説本文中に半角空白（`0x20`）が現れたら即座に指摘し、ワンクリックで全角空白（`　`）へ置換できるようにします。

### ② 全角パイプ（`｜`）の禁止
* **ルビ記法の統一**: カクヨムや青空文庫などの小説投稿サイトや組版エンジンでは、ルビ開始記号として全角 `｜` を許容するものもありますが、本プロジェクト（`novelaide`）では前回の改修によって**半角パイプ `|` に厳格に統一**しました。
* **本文混入の防止**: また、小説の地の文や会話文で縦棒「｜」を記号として使うことは基本的にありません。全角パイプが残っているとルビ表記揺れの原因となるため、見つかり次第、半角 `|` へ直すよう促します。

## 2. 校正ルールの段階的実装ロードマップ

文章校正ルールは多岐にわたります。一度にすべてを詰め込むのではなく、**影響範囲や検知精度、修正の容易さに応じて4つのフェーズで段階的に実装を進める**ロードマップを策定しました（仕様書: [日本語文章校正および形態素解析基盤設計計画.md](../../docs/dev/日本語文章校正および形態素解析基盤設計計画.md)）。

1. **第1段階：記法・文字種チェック（★今回ここから着手）**
   - 半角空白禁止（`novel-no-half-width-space`）★
   - 全角パイプ禁止（`novel-no-full-width-pipe`）★
   - 会話文末の句点 `「〜。」` の除去（実装済み）
   - 三点リーダー2マス `……` の偶数統一（実装済み）
   - 感嘆符・疑問符直後の全角空白チェック（実装済み）
   - ダッシュ2マス `――` 統一チェック（予定）
2. **第2段階：小説の文構造・段落作法ルール**
   - 段落冒頭の一字下げ（行頭全角空白チェック）
   - 括弧直前の不要な空白検知（`「あああ　」` の除去）
   - 文末助動詞の連続重複（「〜た。〜た。〜た。」の3連続以上検知）
3. **第3段階：形態素解析（Lindera）を活用した高度な文法・用字ルール**
   - ら抜き言葉検知（「見れる」→「見られる」等）
   - 同一助詞の重複検知（「の」の3連続以上検知を拡張）
   - 意図しない二重否定検知（「〜ないわけではない」等）
   - 常用漢字・形式名詞の開き辞書の拡充
4. **第4段階：固有名詞・表記揺れチェック（ユーザー辞書連携）**
   - キャラクター名・地名設定資料からの自動辞書生成と表記揺れ検知

## 3. Rustバックエンドでの実装

高速な校正処理を実現するため、Rustクレート `tauri-plugin-novelaid-calibration` の `src/desktop.rs` にルールを追加しました。

行単位の文字ループ（`chars()`）の中で、1文字ずつ確実に検出します。

```rust
// tauri-plugin-novelaid-calibration/src/desktop.rs
let chars: Vec<char> = line.chars().collect();
for (ci, &c) in chars.iter().enumerate() {
    let col = (ci + 1) as u32;

    // ① 半角空白禁止チェック
    if c == ' ' {
        issues.push(CalibrationIssue {
            id: format!("no-half-width-space-{}-{}", line_num, ci),
            rule_id: "novel-no-half-width-space".into(),
            rule_type: "novel_style".into(),
            message: "小説執筆では原則として半角空白は使用しません。全角空白への置換を推奨します".into(),
            range: CalibrationRange {
                start_line: line_num,
                start_column: col,
                end_line: line_num,
                end_column: col + 1,
            },
            suggestion: Some("　".into()), // 全角空白を提案
        });
    }

    // ② 全角パイプ禁止チェック
    if c == '｜' {
        issues.push(CalibrationIssue {
            id: format!("no-full-width-pipe-{}-{}", line_num, ci),
            rule_id: "novel-no-full-width-pipe".into(),
            rule_type: "novel_style".into(),
            message: "ルビ開始記号には半角パイプ「|」を使用します。全角「｜」は使用しません".into(),
            range: CalibrationRange {
                start_line: line_num,
                start_column: col,
                end_line: line_num,
                end_column: col + 1,
            },
            suggestion: Some("|".into()), // 半角パイプを提案
        });
    }

    // ③ 感嘆符・疑問符直後の空白チェック
    // ...
}
```

### 単体テストでの検証
新設したテストケース `test_no_half_width_space_and_full_width_pipe` を含め、Rustのテストスイート全11件がパスすることを確認しました。

```rust
#[test]
fn test_no_half_width_space_and_full_width_pipe() {
    let text = "これは 半角空白 と ｜全角パイプ《ルビ》 のテスト。";
    let chars: Vec<char> = text.chars().collect();
    let mut space_issues = Vec::new();
    let mut pipe_issues = Vec::new();

    for (ci, &c) in chars.iter().enumerate() {
        if c == ' ' { space_issues.push(ci); }
        if c == '｜' { pipe_issues.push(ci); }
    }

    assert_eq!(space_issues.len(), 4);
    assert_eq!(pipe_issues.len(), 1);
}
```
