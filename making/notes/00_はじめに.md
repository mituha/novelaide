本プロジェクトは、小説執筆用エディターを作成するプロジェクトであり、同時にそのシステム構築経過自体も記録・記事化していくものです。  
また、novelaideは、既存の、novelaid-editor、novelaid-editor-nextを再検討、再実装するとともに、その開発過程を再度記事化することを目的として、一から作成しなおします。

フレームワークとしては、Tauriを使用します。
アプリの名称としては、`novelaide`とします。参照するアプリ名と被らない名称とし、また、今回はIDEの名称を掛けて、末尾が`ide`となるようにしています。
なお、色々な部分の共通名称としては、従来通りの`novelaid`を使用してください。コードネーム的には`novelaid-e`です。

## 参照プロジェクト

* novelaid-editor
  + electorn版
  + 現行のアプリ
  + 参考用、読み取り専用
* novelaid-editor-next
  + tauri版
  + novelaid-editorをtauriで再実装途中
  + 参考用、読み取り専用
* novelaid-cli
  + AIエージェント用
  + 今回、機能を内蔵予定
  + 参考用、読み取り専用
* novelaid-editor-docs
  + 共通仕様、ドキュメント類
  + 追記、編集可能


## 開発・実行環境

このシステムを構築する開発基盤は以下の通りです。

* **Antigravity**（Google DeepMind開発のエージェント型開発環境）
  * エージェント実行エンジンおよび専用IDEを活用し、タスクの自律進行やスクリプト連携を行います。
* **Orca**（Orca ADE）
  * 開発支援環境として連携。
* **Tauri**
* **Pi Coding Agent SDK**
  * 小説執筆支援CLIのコアエンジンとして採用。
* **Git**（バージョン管理）
