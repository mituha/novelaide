# 第0回：はじめに —— AI時代に贈る、小説執筆専用IDE「novelaide」開発プロジェクト始動！

はじめまして、こんにちは！

本連載は、小説執筆専用デスクトップエディター **`novelaide`**（ノベルアイド、コードネーム: `novelaid-e`）を一から創り上げていく、システム構築とプログラミングのメイキング記録です。

「小説家が本当に欲しかった執筆環境」を形にするため、最先端の軽量デスクトップフレームワーク **Tauri 2.x** と、自律型AIエージェント技術を駆使して開発を進めています。

本連載の大きな特徴は、**「システム開発の全工程をそのまま記録・公開し、読者のみなさんも同じように自分専用の執筆アプリを作れるようになること」** です。

今回は記念すべき第0回として、本プロジェクトを立ち上げた背景、アプリ名に込めた想い、そして開発基盤についてご紹介します！

---

## 1. なぜ今、小説執筆エディターを一から創り直すのか？

これまで私たちは、Electronフレームワークを用いた小説エディター **`novelaid-editor`** を開発・運用してきました。

ルビ（`|漢字《ルビ》`）のリアルタイムプレビュー、文字数・原稿用紙換算カウント、Frontmatterによる設定資料管理、Gitによる執筆履歴の保存など、多くの機能を盛り込み、実際の長編小説の執筆現場で活用されてきました。

しかし、長編を執筆し続ける中で、いくつかの新たな課題や可能性も見えてきました。

1. **Electronの重量感から、Tauriの超軽量・爆速ネイティブへ**:
   - Electronは使い慣れたWeb技術で開発できる反面、メモリ消費やアプリサイズが大きくなりがちです。執筆に没頭するためには、起動が速く、軽快に動作するエディターが不可欠です。そこで、Rustをバックエンドとする次世代フレームワーク **Tauri 2.x** で一新することを決断しました。
2. **AIネイティブな執筆体験の統合**:
   - 近年のAI（LLM）の進化は目覚ましく、プロットの壁打ち、描写の言い換え、誤字脱字の校正スキャンなど、作家の心強い「共同執筆パートナー」となり得ます。後付けのプラグインではなく、エディターのコア部分と深く連携したAIエージェント（`pi-coding-agent` 基盤）を内蔵することを目指しました。
3. **開発プロセスの完全オープン化（追体験可能な記事化）**:
   - 「完成したアプリ」を配布するだけでなく、「AIエージェント（Antigravity）と人間がどのようにペアプログラミングをしてアプリを作り上げていくのか」という経過そのものを丁寧に記事化し、プログラミング初心者の方でも一歩ずつ真似して作れる教材としても機能させたいと考えました。

過去の知見を土台にしつつ、妥協なく一から再構築するプロジェクト、それが **`novelaide`** です。

---

## 2. アプリ名「novelaide」に込めた想い

アプリの名称は **`novelaide`**（ノベルアイド）と名付けました。

* **novel**（小説）＋ **aid**（支援・助け）
* そして、末尾の **ide** は、プログラマーが愛用する **IDE**（Integrated Development Environment：統合開発環境）の頭文字を掛けています。

プログラマーがVSCodeなどの高機能なIDEを使って快適にコードを書くように、小説家にも「原稿執筆、キャラクター設定、プロット管理、差分履歴、組版プレビュー、AI推敲」がシームレスに繋がった**「小説執筆のための統合環境」**を届けたい。そんな想いが込められています。

なお、内部モジュールやツール群の共通ブランド名としては、親しみやすい従来の **`novelaid`** を統一して使用しています。

## 4. 開発・実行基盤（現代のAI駆動開発環境）

本システムを構築する開発基盤は、最先端のテクノロジーで固められています。

* **Antigravity**（Google DeepMind開発の自律型コーディング環境）:
  - エージェント実行エンジンおよび専用IDEを活用し、タスクの自律進行やスクリプト連携を行います。
* **Tauri 2.x + Rust**:
  - デスクトップアプリの基盤。OSネイティブの高速ファイルアクセスと最小限のメモリフットプリントを実現します。
* **React 19 + TypeScript + Vite**:
  - 柔軟で高速なUIレンダリングと、確実な型安全性を両立します。
* **Pi Coding Agent SDK**:
  - 自律型AIエージェントを駆動する標準基盤。LM Studio等のローカルLLMともセキュアに接続します。
* **Git**:
  - 細かい作業区切りごとのバージョン管理と変更履歴の追跡。

## 5. プロジェクトのディレクトリ構成とコンテキスト分離

本リポジトリでは、「小説の執筆作業」「システムの開発仕様」「メイキング記録」が混ざって混沌としないよう、最初から厳密なコンテキスト分離を行っています。

```text
novelaide/
├── docs/             # 将来的にユーザーへ公開する公式ドキュメント
│   ├── dev/          # 開発仕様書、システム設計メモ（日本語タイトル）
│   └── manual/       # novelaide のユーザー向け操作マニュアル
├── making/           # システム構築の全記録（小説本編とは完全に独立）
│   ├── logs/         # 日々の作業手順、ユーザープロンプト原文、質疑応答（YYYY-MM-DD.md）
│   └── notes/        # 本連載記事（note.com等への投稿用Markdownと画像）
└── src/              # アプリケーションのソースコード（React / TypeScript / Rust）
```

AIエージェントと開発を進める上でも、「どのフォルダに何を書くべきか」が明確になっているため、ドキュメントの鮮度とコードの品質が常に最高水準に保たれます。
