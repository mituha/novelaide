# tauri-plugin-novelaid-calibration ドキュメント一覧

## 📖 仕様書一覧

* **[日本語文章校正および形態素解析基盤設計計画](./日本語文章校正および形態素解析基盤設計計画.md)**
  - ルールレジストリ、小説作法ルール群（三点リーダー、会話文末、重言等）、形態素解析連携の全体設計。
* **[Lindera形態素解析エンジン組み込み計画](./Lindera形態素解析エンジン組み込み計画.md)**
  - 純Rust製形態素解析エンジン Lindera 6.2.0 および組み込み IPADIC 辞書の採用とトークナイズパイプライン。
* **[形態素解析エンジン辞書登録およびキャラクター語尾仕様](./形態素解析エンジン辞書登録およびキャラクター語尾仕様.md)**

* **[形態素解析デバッグおよびプロジェクト辞書確認仕様](./形態素解析デバッグおよびプロジェクト辞書確認仕様.md)**
