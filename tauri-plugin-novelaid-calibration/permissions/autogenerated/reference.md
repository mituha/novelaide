## Default Permission

Default permissions for novelaid-calibration plugin

#### This default permission set includes the following:

- `allow-ping`
- `allow-check-text`
- `allow-tokenize-text`
- `allow-get-ruby-candidates`
- `allow-update-project-dictionary`
