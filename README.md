# novelaide

小説執筆のための次世代デスクトップ統合執筆環境（IDE）です。  
**Tauri 2.x**, **Rust**, **React 19**, **TypeScript**, そして **Pi Coding Agent SDK** を用いて一から設計・構築されています。

左手で原稿を紡ぎ、右手で世界観を紐解くための「左右独立マルチタブ分割エリア」、縦書き文庫本組版プレビュー、安心のGit履歴管理、そしてメモリ上の未保存テキストまで理解する「AI執筆パートナー」を統合し、作家が物語の世界に没頭できる最高速かつ軽量な執筆体験を提供します。

---

## はじめに

このプロジェクトは、作者が自身のWEB小説執筆をより快適にするために開発しています。  
また、Google DeepMind発の自律型コーディングAIエージェントを活用した対話型プログラミング（バイブコーディング）によって開発を進めるための実験的プロジェクトでもあります。

そのため、本ソフトウェアは現状有姿（**As is**）で公開されています。  
本READMEや `docs/` 配下のドキュメント類も開発プロセスの中で随時更新されているため、**未実装の内容や、実際の実装とは異なる記述が含まれる可能性があります**。

## 📖 執筆者の方へ（主な機能）

`novelaide` は、長編小説の執筆から推敲・校正に至るすべての工程を支える機能を備えています。

* **左右独立マルチタブ分割エリア（参照カウント式ライフサイクル）**:
  - ドキュメント表示エリア自体が2つの独立したタブバー付きペイン（左ペイン・右ペイン）として構成されています。
  - 「左で第1章を執筆しながら、右で第2章や設定メモを並列して開く」といった自由なレイアウトが可能。
  - 左右で同じファイルを開いた場合でもメモリ上の実体（`DocumentState`）は1つのみ保持されるため、編集内容は完全にリアルタイム自動同期されます。
  - 未保存の変更がある状態でタブやペインを閉じても、確認ダイアログ不要で自動的にディスクへ安全保存されます。
* **小説執筆特化エディター & ルビ・組版プレビュー**:
  - Monaco Editor を小説執筆向けに最適化。
  - カクヨム・なろう形式のルビ記法（`|漢字《ルビ》`）や傍点（`《《強調》》`）の入力・描画に対応。
  - **同一ペイン内でのプレビュー切替**、または**「分割プレビュー」**による別窓展開が可能。文庫本スタイルの縦書きリーダー表示と、Web小説向けの横書き表示をワンクリックで切り替えられます。
* **AI執筆パートナー（Pi Coding Agent SDK 準拠）**:
  - 4つの執筆ペルソナ（執筆パートナー、担当編集者、校正係、作中人物）を瞬時に切り替え可能。
  - ディスク上の保存ファイルだけでなく、**画面上で編集中（未保存）の最新テキストバッファをAIが直接参照**して校正スキャンやルビ抽出を実施。
  - スラッシュコマンド（`/ruby`, `/proofread`, `/check`, `/info`, `/help`）によるキーボード完結の高速操作。
  - LM Studio等のローカルLLMエンドポイント（`http://localhost:1234/v1`）を自動検出し、完全オフラインで原稿データを外部に送信することなく安全に利用可能。
* **安心のバージョン管理・履歴復元 (Git)**:
  - 執筆内容の変更履歴をGitで自動的・明示的にコミット。
  - Monaco Diff Editor により、過去のバージョンとの差分を左右比較しながら確認・復元可能。
* **リアルタイム原稿用紙換算カウント**:
  - 本文全体および選択テキストの文字数（空白含む／除く）、行数、原稿用紙（400字詰）換算枚数をステータスバーに常時表示。
* **設定資料 & Frontmatter管理**:
  - 作品内の登場人物、世界観、プロット設定資料をFrontmatter（YAML）とMarkdownで構造化管理。

## 💻 開発者の方へ（技術スタックと設計思想）

モダンで堅牢なアーキテクチャと、拡張性の高いプラグイン構造を採用しています。

- **コアフレームワーク**: [Tauri 2.x](https://tauri.app/) / [Rust](https://www.rust-lang.org/)
- **フロントエンド**: [React 19](https://react.dev/) / [TypeScript](https://www.typescriptlang.org/) / [Vite](https://vite.dev/)
- **エディターエンジン**: [Monaco Editor](https://microsoft.github.io/monaco-editor/)
- **AIエージェント基盤**: `@earendil-works/pi-agent-core`, `@earendil-works/pi-ai`
- **プラグイン分離アーキテクチャ**:
  - `tauri-plugin-novelaid-fs`: Rustネイティブの安全なファイル操作とFrontmatterキャッシュ
  - `tauri-plugin-novelaid-ai`: 自律型AIセッション管理および執筆支援Extension基盤
  - `restar-app-settings` / `restar-app-git`: アプリ共通の設定・Git操作コンポーネント

## 🛠 開発環境のセットアップ (Windows / PowerShell)

開発には Windows 環境と PowerShell (`pwsh`) を推奨しています。

### 1. 前提条件の確認
- **Node.js**: v20以上推奨
- **Rust**: 最新の `stable` ツールチェーン（`cargo`, `rustc`）
- **C++ ビルドツール**: Visual Studio C++ Build Tools 等

### 2. リポジトリのクローンとインストール

```pwsh
# リポジトリのクローン
git clone https://github.com/mituha/novelaide.git
cd novelaide

# 依存パッケージのインストール
npm install
```

### 3. プラグインのビルド

```pwsh
# 内蔵プラグイン（FS / AI）の TypeScript 定義をビルド
npm run build:plugins
```

### 4. 開発モードでの起動

```pwsh
# Tauri 開発サーバーの起動（フロントエンド + デスクトップウィンドウ）
npm run tauri dev
```

### 5. プロダクションビルド

```pwsh
# フロントエンドの型検査とバンドルビルド
npm run build

# デスクトップインストーラー / 実行可能ファイルの生成
npm run tauri build
```
