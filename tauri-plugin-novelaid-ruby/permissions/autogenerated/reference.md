## Default Permission

Default permissions for novelaid-ruby plugin

#### This default permission set includes the following:

- `allow-format-ruby`
- `allow-format-smart-ruby`
- `allow-transform-to-html`
- `allow-strip-ruby`
- `allow-extract-ruby-text`
- `allow-count-characters`
