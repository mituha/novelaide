# novelaide 公式ドキュメント

小説執筆用デスクトップIDE **`novelaide`**（コードネーム: `novelaid-e`）の公式ドキュメントポータルです。

本エディターは、長編小説の構造管理、Markdown拡張構文、縦書きプレビュー、リアルタイム文字数カウント、AI執筆パートナー、Gitによるバージョン管理、およびバッチ処理ツールを統合した次世代の小説執筆環境です。
