# 汎用エクスプローラーパネル実装仕様書

## 1. 概要とアーキテクチャ方針

本ドキュメントは、**`novelaide`** における **ファイル一覧にとどまらず、「開いているドキュメント」「原稿ファイルツリー」「見出しアウトライン」等を折りたたみ可能なセクションとして統合表示する「汎用エクスプローラーパネル（`ExplorerPanel`）」** の実装仕様を定義するものです。

### 設計方針
1. **アコーディオン式コンテナ**:
   - `ExplorerPanel` は、独立したセクション（`ExplorerSectionPlugin`）を縦に並べ、各セクションの開閉（展開／折りたたみ）や並び替えをサポートする。
2. **セクションの完全なプラグイン化**:
   - `ExplorerRegistry` を通じて、新しいセクション（例: タイムライン、キャラクター一覧、版履歴など）を動的に追加・差し替え可能にする。
3. **既存機能の統合と昇格**:
   - `FileExplorer` を `FileTreeSection` としてラップ。
   - `DocumentOutline` を `OutlineSection` としてラップ。
   - `OpenDocumentsSection` を新設し、編集中のタブを縦並びで一覧操作できるようにする。

## 3. 型定義（`src/types/explorerPlugin.ts`）

```typescript
import React from 'react';
import { DocumentState } from './document';

export interface ExplorerSectionProps {
  activeDocument: DocumentState | null;
  projectPath: string | null;
}

export interface ExplorerSectionPlugin {
  /** 一意なセクションID (例: 'novelaid.explorer.openDocs', 'novelaid.explorer.fileTree') */
  readonly id: string;
  /** セクションヘッダータイトル */
  readonly title: string;
  /** 初期開閉状態 (true: 展開 / false: 折りたたみ、デフォルト: true) */
  readonly defaultExpanded?: boolean;
  /** 表示優先順位 (数値が大きいほど上部に配置) */
  readonly priority: number;
  /** ヘッダー右端のクイックアクション (任意) */
  readonly headerActions?: React.ComponentType<{ sectionId: string }>;
  /** ヘッダー右端のバッジ表示 (任意) */
  readonly badge?: () => number | string | null;
  /** セクション本体コンポーネント */
  readonly component: React.ComponentType<ExplorerSectionProps>;
}
```

## 4. 組み込みセクション仕様

| セクションID | タイトル | 優先度 | デフォルト開閉 | 主な機能 |
|---|---|:---:|:---:|---|
| `novelaid.explorer.openDocs` | 開いているドキュメント | 100 | 展開 | タブ一覧の縦並び表示、未保存●、閉じる×、クリックアクティブ化 |
| `novelaid.explorer.fileTree` | 原稿ファイル | 90 | 展開 | プロジェクトフォルダー配下の階層ファイルツリー操作 |
| `novelaid.explorer.outline` | 見出しアウトライン | 80 | 展開 | 選択中ドキュメントの章・節見出し抽出とジャンプ |
