# エピソードナビゲーター仕様

## 1. 概要

本機能は、小説執筆エディター（`DocumentPane`）の最下部（フッター領域）において、同一フォルダ内に存在する前後の小説エピソード（`novel` 原稿）へ直感的に移動できるようにするナビゲーション機能である。
旧 Electron 版（`novelaid-editor`）の `NovelNavigator` を Tauri 版アーキテクチャに合わせて再実装したものである。

---

## 2. 設計方針

1. **シンプルで堅牢な遷移（タブを増やさないインプレイス移動）**:
   - 移動時に新しいタブを次々開くのではなく、既存の `closeTab(activePath, paneId)` を実行した直後に `openDocument(targetPath, { paneId, viewMode })` を呼び出す。
   - `closeTab` の内部機構により、未保存の変更がある場合は自動的に保存され、参照カウントの安全管理も保証される。
   - 複雑な低レベルのタブ配列置換ロジックを排除し、すでに十分検証された公開 API の組み合わせのみで構築することでバグ混入リスクを最小限に抑える。
2. **対象ドキュメントの限定（`novel` 専用）**:
   - 対象は小説原稿ファイル（`documentType === 'novel'`）のみとする。設定資料（`markdown`）や画像・CSS等は対象外とする。
   - フッター自体も `novel` 形式を表示している場合にのみ描画され、前後エピソードが存在しない（単独ファイル）場合は表示されない。
3. **自然順序ソート（Natural Order Sort）**:
   - 同一フォルダ内の兄弟 `novel` ファイルを、数値を含む自然順序（`localeCompare(..., { numeric: true, sensitivity: 'base' })`）で整列する。
   - これにより、`01.novel`, `02.novel` や `第1話`, `第2話`, `第10話` といったエピソードが作家の意図通りの順序で前後にナビゲートされる。

## 3. コンポーネント構成

### 3.1. `EpisodeNavigator` (`src/components/Editor/EpisodeNavigator.tsx`)

* **Props**:
  * `activePath: string`: 現在アクティブなドキュメントの絶対パス。
  * `documentType: NovelaidDocumentType`: ドキュメント種別（`'novel'` の時のみ有効）。
  * `paneId: PaneId`: 表示中のペイン識別子（`'editor.left'` または `'editor.right'`）。
  * `viewMode: DocumentViewMode`: 現在の表示モード（`editor`, `preview`, `reader` 等を維持）。
* **内部動作**:
  1. `documentType !== 'novel'` の場合は即座に何もしない（`null` を返却）。
  2. `activePath` の親ディレクトリを取得し、`fileService.readDirectory(parentDir, false)` で同階層のエントリを取得。
  3. `!entry.isDirectory && entry.documentType === 'novel'` のエントリを自然順序ソート。
  4. 現在のファイルのインデックスを特定し、直前のエピソード（`prevEpisode`）および直後のエピソード（`nextEpisode`）を算出。
  5. 前後のエピソードがいずれも存在しない場合は `null` を返却。
  6. クリック時に `closeTab` → `openDocument` を実行してスムーズに遷移。

### 3.2. スタイル定義 (`src/components/Editor/EpisodeNavigator.css`)

* フッター固定バーデザイン:
  * 背景: `var(--bg-secondary)`
  * 上部境界線: `1px solid var(--border-primary)`
  * 高さ: `min-height: 36px`
  * 左側に「前の話」、右側に「次の話」を `justify-content: space-between` で配置。
  * テキストは通常時 `var(--text-muted)`、ホバー時に `var(--text-primary)` とホバー背景 `var(--bg-hover)`。
  * タイトルが長い場合は `text-overflow: ellipsis` で省略表示。

## 4. `DocumentPane` との統合

`src/components/DocumentPane/DocumentPane.tsx` の JSX 最下部に配置：

```tsx
<div className={`document-pane-container pane-${paneSide} view-mode-${viewMode}`}>
  <FileNameHeader ... />
  <div className="document-pane-content">
    <Component ... />
  </div>
  <EpisodeNavigator
    activePath={document.path}
    documentType={document.documentType}
    paneId={paneId}
    viewMode={viewMode}
  />
</div>
```

`DocumentPane.css` において、`.document-pane-content` に `flex: 1; min-height: 0;` を設定することで、タイトルヘッダーとフッターナビゲーターに挟まれたエディター領域が過不足なく伸縮するようにレイアウトされている。
