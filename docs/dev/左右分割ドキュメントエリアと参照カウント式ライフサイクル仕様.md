# 左右分割ドキュメントエリアと参照カウント式ライフサイクル仕様書

## 1. 概要

本ドキュメントは、**`novelaide`** におけるドキュメント表示エリアを、従来の「1つのアクティブドキュメントに対するエディター・プレビュー内包分割」から、`novelaid-editor` と同様の**「複数タブ対応のドキュメント表示ペイン自体を左右に配置する2分割エリア構造」**へと拡張するための設計仕様です。

### 1.1 背景と目標

- **実体（DocumentState）の単一性**:
  - 同一ドキュメントを左右両方のペインで開いた場合でも、メモリ上の実体（`content`, `metadata`, `isDirty`）は1つのみ保持し、編集内容をリアルタイムに自動同期します。
- **参照カウント式ライフサイクル管理**:
  - ドキュメントの生存期間（ライフサイクル）は、「いずれかの UI View（エディターペイン、パネル等）に表示されている間のみ」とします。
  - 各ドキュメントは自身を表示している View リスト（`views`）を保持し、全ての View から参照されなくなった瞬間にメモリから安全にアンロードします。
- **柔軟なペイン制御とプレビュー連携**:
  - 同一ペイン内での `edit` ↔ `preview`（`reader`）切り替えと、反対ペインへのプレビュー表示展開の両方をサポートします。
  - 1ペイン状態は常に「左ペイン」として統一管理し、右ペインのみが残った場合は自動的に左ペインへ昇格します。
- **作家ファーストの自動保存**:
  - タブを閉じる際は確認ダイアログを出さず、自動的に保存して閉じます。

## 2. データ構造の設計

### 2.1 View 参照とドキュメント状態 (`src/types/document.ts`)

```ts
/**
 * ペインの識別子
 * 将来的な多分割（3分割・縦分割）にも拡張可能な文字列ID
 */
export type PaneId = 'editor.left' | 'editor.right';

/**
 * ドキュメント表示モードの種類
 */
export type DocumentViewMode = 'none' | 'editor' | 'canvas' | 'reader' | 'preview';

/**
 * View 参照情報（どのViewに、どの表示モードで表示されているか）
 */
export interface DocumentViewRef {
  /** Viewの識別ID (例: 'editor.left', 'editor.right', 'panel.outline', 'context') */
  viewId: string;
  /** 当該Viewにおける表示モード (省略またはnullの場合はViewModeを持たない参照) */
  viewMode?: DocumentViewMode | null;
}

/**
 * 開いているドキュメントの状態（単一の実体）
 */
export interface DocumentState {
  path: string;
  baseName: string;
  fileTitle: string;
  /** 原稿本文の単一実体（左右ペイン間で完全共有） */
  content: string;
  /** Frontmatter設定等のメタデータ実体 */
  metadata: Record<string, any>;
  documentType: NovelaidDocumentType;
  isDirty: boolean;

  /** 現在このドキュメントを参照・表示している View 一覧（参照カウント式） */
  views: DocumentViewRef[];
}
```

## 3. ライフサイクル管理とペイン仕様

### 3.1 参照カウント式ライフサイクル

1. **ファイルを開く (`openDocument`)**:
   - `openDocuments` に対象 `path` が存在しない場合:
     - `fileService.readFile(path)` でディスクから読み込み。
     - `views: [{ viewId: targetPane, viewMode: initialMode }]` を初期設定して `openDocuments` に登録。
   - 既に `openDocuments` に存在する場合:
     - 既存の `DocumentState` を再利用。
     - 当該 `targetPane` の参照が `views` になければ追加、既存なら `viewMode` を更新。
2. **タブを閉じる (`closeTab`)**:
   - 指定された `paneId` の `DocumentViewRef` を `views` 配列から除外。
   - **未保存（`isDirty: true`）の場合**:
     - 確認ダイアログは出さず、直ちに `fileService.writeFile` を実行してディスクに保存。
   - **参照カウント判定**:
     - `views.length === 0`（すべてのペインおよびパネルから参照がなくなった）になった瞬間、`openDocuments` 配列から完全削除（アンロード）。
3. **内容編集 (`updateContent`)**:
   - `DocumentState.content` を更新（`isDirty = true`）。
   - 単一のステートであるため、左右両ペインに同一ドキュメントを開いていた場合（例: 左が編集、右がプレビュー）、自動的に完全同期描画される。

### 3.2 プレビュー表示の仕様

- **同一ペイン内切り替え**:
  - 現在のペインにおける自身の `viewMode` を `editor` ↔ `preview`（小説形式なら `reader`）に切り替え。
- **別ペインへのプレビュー展開 (`openPreviewInSplit`)**:
  - 反対側のペイン（通常は `editor.right`）を展開（`isSplit = true`）。
  - 反対側ペインに同一ドキュメントの参照（`viewId: 'editor.right', viewMode: 'preview'` または `'reader'`）を追加し、アクティブタブに設定。

### 3.3 ペインの開閉と昇格ルール

- **右ペインを閉じた場合 (`closeRightPane` / `toggleSplit`)**:
  - `editor.right` の参照を持つすべてのドキュメントから `editor.right` を解除。
  - 他の参照を持たないドキュメントは自動保存の上でアンロード。
  - `isSplit = false`, `activePane = 'editor.left'`。
- **左ペインのタブをすべて閉じた場合**:
  - 右ペインにのみタブが存在する場合、右ペインの `views`（`editor.right`）をすべて `editor.left` に書き換え、左ペインへ一括昇格。
  - 常に「1ペイン状態のときは左ペイン（`editor.left`）」として扱う。
- **エクスプローラーからのオープン先**:
  - 現在フォーカスされているペイン（`activePane`）に開く。

## 4. UI コンポーネント構造

```text
┌────────────────────────────────────────────────────────┐
│ MainLayout                                             │
│ ┌────────────────────────────────────────────────────┐ │
│ │ DocumentArea (左右分割コンテナ)                     │ │
│ │ ┌──────────────────────┬───┬─────────────────────┐ │ │
│ │ │ Pane: editor.left    │   │ Pane: editor.right  │ │ │
│ │ │ ┌──────────────────┐ │ S │ ┌─────────────────┐ │ │ │
│ │ │ │ EditorTabs (Left)│ │ P │ │EditorTabs(Right)│ │ │ │
│ │ │ ├──────────────────┤ │ L │ ├─────────────────┤ │ │ │
│ │ │ │ DocumentPane     │ │ I │ │ DocumentPane    │ │ │ │
│ │ │ │ (viewMode: edit) │ │ T │ │ (viewMode: prev)│ │ │ │
│ │ │ └──────────────────┘ │ T │ └─────────────────┘ │ │ │
│ │ └──────────────────────┴───┴─────────────────────┘ │ │
│ └────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

- 各ペイン（`editor.left`, `editor.right`）がそれぞれ独立した `EditorTabs` と `DocumentPane` を持つ。
- 将来的にペインが3つ以上（または縦分割）に拡張される場合も、コンポーネントをループ描画するだけで対応可能。
