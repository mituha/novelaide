# エディタータブヘッダーおよびコンテキストメニュー仕様

## 1. 概要

本仕様書は、小説執筆デスクトップIDE `novelaide` におけるエディタータブヘッダーのアクションツールバー、およびタブ右クリック時のコンテキストメニューの構造・動作仕様を定義するものです。

### 目的
- 左右ペインの非対称性（右ペインにのみ閉じるボタンが存在する等）を解消し、両ペインを等価な執筆領域として整えます。
- タブの右クリック操作を整理し、「左側のタブを閉じる」「反対側ペインへ移動」「表示モード切替」を直感的に実行できるようにします。
- 実行不可能な項目を安易に非表示とせず、メニュー位置のマッスルメモリー（操作記憶）を維持するためグレーアウト（Disabled）制御を徹底します。

---

## 2. タブ右クリックコンテキストメニューの仕様

コンテキストメニューは論理的な3つのグループに分類し、セパレーターで視覚的に整理します。

```
[閉じる]
[他のタブを閉じる]
[右側のタブを閉じる]
[左側のタブを閉じる]
[すべてのタブを閉じる]
---------------------------------- (セパレーター)
[プレビューで開く / エディターで開く] (※novel/markdown時のみ)
---------------------------------- (セパレーター)
[横に分割して開く]
[右ペインへ移動 / 左ペインへ移動]
[分割プレビューで開く] (※novel/markdown時のみ)
```

### 2.1 メニュー項目一覧と動作・Disabled条件

| グループ | 項目名 | アイコン | 動作 | Disabled（無効化）条件 |
| :--- | :--- | :---: | :--- | :--- |
| **閉じる系** | **閉じる** | `X` | 当該タブを閉じる | なし |
| | **他のタブを閉じる** | - | 自身以外のペイン内全タブを閉じる | 当該ペインのタブが1つのみ |
| | **右側のタブを閉じる** | - | 自身より右側にある全タブを一括終了 | 自身がペイン内の一番右端のタブ |
| | **左側のタブを閉じる** | - | 自身より左側にある全タブを一括終了 | 自身がペイン内の一番左端のタブ |
| | **すべてのタブを閉じる** | - | 当該ペイン内の全タブを閉じる | なし |
| **モード切替** | **プレビューで開く** /<br>**エディターで開く** | `Eye` /<br>`Edit3` | 当該タブの表示モード（editor ⇄ preview/reader）を切り替える | 非対応ドキュメント形式（画像・コード等）では項目自体を非表示 |
| **分割・移動** | **横に分割して開く** | `Split` | 反対側ペインに同一ドキュメントを複製表示する（既存ならアクティブ化） | なし |
| | **右ペインへ移動** /<br>**左ペインへ移動** | `ArrowRightLeft` | 反対側ペインで開き、現在のペインからは閉じる（Move動作） | なし |
| | **分割プレビューで開く** | `BookOpen` | 反対側ペインにプレビュー形式で開く | 非対応ドキュメント形式では項目自体を非表示 |

### 2.2 Disabled（無効化）スタイルの原則
- 無効化されたメニュー項目は `tab-context-menu-item disabled` クラスを付与し、`opacity: 0.38`、`pointer-events: none`、`cursor: default` で描画します。
- メニューの行数や項目の位置が状況によって変動しないため、高速なマウス操作でも誤操作を防ぎます。

### 2.3 「右ペインを閉じる」の完全撤廃
- 従来のコンテキストメニューにあった「右ペインを閉じる」は廃止します。
- 「すべてのタブを閉じる」を実行すれば、ペイン内の全タブがクローズされ、右ペインの場合は自動的に分割状態が解除されるため、単一の直感的な操作に一本化します。

## 3. ヘッダーアクションツールバー（右端）の仕様

左右ペインを完全に対称化するため、左右ともに**タブバーの右端**にアクションボタングループを配置します（案A: 右端統一モデル）。

```
[左ペイン]  [▼ タブ1 | タブ2] --------------------- [[表示] [横に分割] [分割プレビュー]]
[右ペイン]  [▼ タブA | タブB] --------------------- [[表示] [横に分割] [分割プレビュー]]
```

### 3.1 左右ペインのアクション一覧

| アクション | アイコン | 左ペイン（`editor.left`）の挙動 | 右ペイン（`editor.right`）の挙動 |
| :--- | :---: | :--- | :--- |
| **表示モード切替** | `Eye` / `Edit3` | 現在のアクティブタブのモード切替（エディター ⇄ プレビュー） | 同左 |
| **反対側に分割表示** | `Columns2` | 右ペインに同一ドキュメントを開く（複製） | 左ペインに同一ドキュメントを開く（複製） |
| **反対側にプレビュー表示** | `BookOpen` | 右ペインにプレビュー形式で開く | 左ペインにプレビュー形式で開く |

### 3.2 右ペイン × ボタンの撤廃
- 右ペインの右端に存在していた独立した閉じるボタン（`pane-close-action-btn`）は撤廃します。
- タブの `×` ボタンとの押し間違いを根絶し、左右のペイン構成を完全に統一します。
