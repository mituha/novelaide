# Monaco Editor サジェスチョンおよび小説補完仕様

## 1. 概要

本仕様書は、小説執筆デスクトップIDE `novelaide` における Monaco Editor の入力補完（サジェスチョン / IntelliSense）の表示契機、抑制方針、手動トリガー仕様、および補完候補コンテンツを定義するものです。

### 目的
- 小説執筆中のタイピング時に、意図しない補完ポップアップが自動出現して視界を遮り、思考を阻害する問題を根本的に解消します。
- 通常入力時の Enter キーによる意図しない文字列確定（改行誤爆）を撲滅します。
- 作家が明示的に希望した瞬間にのみ `Ctrl + Space` で候補を呼び出し、Enter キーで素早く確定できる快適な執筆環境を提供します。

---

## 2. サジェスチョン制御仕様

Monaco Editor のオプション設定により、**「自動表示の完全抑制」** と **「手動呼び出し時の快適な確定」** を両立させます。

```
[通常の文字入力 / タイピング]
   │
   ├─ quickSuggestions: false
   ├─ suggestOnTriggerCharacters: false
   └─ wordBasedSuggestions: "off"
   │
   ▼
【完全サイレント（ポップアップは一切自動出現しない）】
Enter キー ──▶ 通常の段落改行（誤爆なし）

[作家が候補を欲しい時]
   │
   ├─ 明示的に Ctrl + Space を押下
   │
   ▼
【候補ウィンドウが意図して出現】
   ├─ ルビ記法スニペット (｜漢字《かんじ》)
   ├─ 傍点記法スニペット (《《強調》》)
   ├─ 登場人物名 / 地名・舞台名
   └─ 三点リーダー (……) / ダッシュ (――)
   │
   ▼
上下キーで選択 ──▶ Enter キーで直感的に確定！ (acceptSuggestionOnEnter: "on")
```

### 2.1 Monaco Editor オプション設定一覧

| オプション名 | 設定値 | 役割と効果 |
| :--- | :---: | :--- |
| **`quickSuggestions`** | **`false`** | タイピング中の自動ポップアップを完全停止 |
| **`suggestOnTriggerCharacters`** | **`false`** | 記号入力（`|` や `:` 等）時の自動トリガーを停止 |
| **`wordBasedSuggestions`** | **`"off"`** | ファイル内の英単語等を勝手に拾って候補に出すノイズを排除 |
| **`acceptSuggestionOnEnter`** | **`"on"`** | ユーザーが `Ctrl + Space` で意図して呼び出した候補を Enter キーで素早く確定 |
| **`tabCompletion`** | **`"on"`** | Tab キーでも補完確定を可能に |
| **`suggest.showWords`** | **`true`** | `CompletionItemKind.Text`（三点リーダー・ダッシュ等）を表示可能に（`wordBasedSuggestions: "off"` で自動単語収集ノイズは停止済み） |
| **`suggest.showSnippets`** | **`true`** | ルビ・傍点等のスニペット候補を有効化 |

## 3. 提供する補完候補コンテンツ仕様

明示的な `Ctrl + Space` 呼び出し時に、小説執筆に特化した以下の候補を提供します。

### 3.1 補完候補の優先順位（表示順序）

執筆中の使用頻度を最優先とし、`sortText` を用いて候補リストの並び順を厳密に制御しています。最も頻繁に用いられる **三点リーダー** および **ダッシュ** を最上位に配置し、その次に **ルビ記法**、**傍点記法**、**閉じ括弧** が並びます。

| 表示順 | 候補名 | `sortText` | 種別 | 概要 |
| :---: | :--- | :--- | :---: | :--- |
| **1** | `……` | `01_ellipsis` | `Text` | 三点リーダー（2倍角） |
| **2** | `――` | `02_dash` | `Text` | ダッシュ（2倍角） |
| **3** | `ルビ: ｜漢字《かんじ》` | `03_ruby` | `Snippet` | ルビ記法（novelaid標準） |
| **4** | `傍点: 《《強調》》` | `04_bouten` | `Snippet` | 傍点・強調記法 |
| **5** | `」` 等（対応括弧） | `05_close_bracket` | `Text` | 開き括弧に対応する閉じ括弧 |

### 3.2 単語選択時の完全一致マッチングと置換仕様

単語（文字列）を選択した状態で `Ctrl + Space` を呼び出した際、Monaco Editor が選択テキストをプレフィックス照合する仕様に対応し、各候補の `filterText` 先頭に `selectedText` を動的付与しています。

- これにより、どんな文字列を選択していても完全前方一致（最高スコア）でマッチし、サジェストから除外されることなく確実に候補が表示されます。
- 確定時には、選択していた単語を保持したまま `《《単語》》` や `｜単語《${1:よみ}》` へ綺麗に置き換わります。

- **三点リーダー（最優先）**:
  - 表示名: `……`（ショートカット: `Alt + .`）
  - 挿入テキスト: `……`
  - `filterText`: 選択時は `${selectedText} …… ... さんてん リーダー`
- **ダッシュ（優先度2）**:
  - 表示名: `――`（ショートカット: `Alt + -`）
  - 挿入テキスト: `――`
  - `filterText`: 選択時は `${selectedText} ―― -- ダッシュ だっしゅ`
- **ルビ記法**:
  - 表示名: `ルビ: ｜漢字《かんじ》`
  - 挿入テキスト:
    - **文字列選択時**: `｜${選択テキスト}《${1:よみ}》`（選択文字を親文字とし、読み仮名入力へTabジャンプ）
    - **非選択時**: `｜${1:漢字}《${2:よみ}》`（Tabキーで漢字と読みに順次ジャンプ）
  - `filterText`: 選択時は `${selectedText} ルビ るび ruby 漢字 かんじ ｜|`
- **傍点記法**:
  - 表示名: `傍点: 《《強調》》`
  - 挿入テキスト:
    - **文字列選択時**: `《《${選択テキスト}》》`（選択内容をそのまま残して傍点で囲む）
    - **非選択時**: `《《${1:テキスト}》》`（Tabキーでテキスト入力位置へフォーカス）
  - `filterText`: 選択時は `${selectedText} 傍点 ぼうてん 強調 きょうちょう 《《`
- **対応する閉じ括弧**:
  - 開き括弧に対応する閉じ括弧（未対の場合に候補提示）。
  - 括弧のペア定義は `tauri-plugin-novelaid-ruby`（`NOVEL_BRACKET_PAIRS`）により一元管理されます。

### 3.3 括弧ペアの一元管理（`novelaid-ruby`）

エディター内でのハードコードを排除し、小説固有の記法を担う `tauri-plugin-novelaid-ruby` パッケージにおいて括弧のペア情報およびメタデータを定義・一元管理します。

| 開始括弧 | 終了括弧 | 名称 / 用途 | 補完ラベル |
| :---: | :---: | :--- | :--- |
| `「` | `」` | 鉤括弧（会話文） | `」 を閉じる` |
| `『` | `』` | 二重鉤括弧（セリフ・強調・電話等） | `』 を閉じる` |
| `（` | `）` | 丸括弧（心情・補足） | `） を閉じる` |
| `【` | `】` | 隅付き括弧（見出し・場面） | `】 を閉じる` |
| `［` | `］` | 角括弧 | `］ を閉じる` |
| `〈` | `〉` | 山括弧 | `〉 を閉じる` |
| `《` | `》` | 二重山括弧（ルビ等） | `》 を閉じる` |
| `〔` | `〕` | 亀甲括弧 | `〕 を閉じる` |

### 3.4 作品ナレッジ（メタデータ連携）
- **登場人物名**（`Kind: User`）:
  - 作品フォルダー内の `characters/*.md` に登録された登場人物名。
  - 複雑な漢字表記のキャラクター名を正確に補完。
- **地名・舞台**（`Kind: Class`）:
  - 作品フォルダー内の `locations/*.md` 等に登録された地名・用語。

## 4. ドキュメントタイプ別の適用方針

- **小説原稿（`novel`）およびマークダウン（`markdown`）**:
  - 本仕様（自動表示完全抑制、`Ctrl + Space` 手動トリガー、Enter確定）を常時適用。
- **設定ファイル・コードファイル（`code` / `DocumentType::Code`）**:
  - 設定ファイル（`.gitignore`, `.json`, `.yaml` 等）の編集時には、一般的なコードエディターとしての言語補完（JSONスキーマ補完等）を適切に提供。
