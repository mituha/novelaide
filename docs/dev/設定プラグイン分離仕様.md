# 設定プラグイン分離実装仕様書（tauri-plugin-restar-settings）

## 1. 概要とアーキテクチャ方針

本ドキュメントは、**`novelaide`** における設定システムを、他のTauriアプリでも使用可能な共通プラグイン **`tauri-plugin-restar-settings`（npm: `restar-app-settings`）** としてプロジェクト内部で構造的に分離する実装仕様を定義するものです。

---

## 2. ディレクトリ構成

```text
tauri-plugin-restar-settings/
├── Cargo.toml                       # Rustクレート定義
├── build.rs                         # Tauriコマンドパーミッション生成
├── permissions/
│   └── default.toml                 # デフォルト許可パーミッション
├── src/
│   ├── lib.rs                       # プラグイン初期化
│   ├── commands.rs                  # load_settings, save_settings, get_settings_path
│   └── error.rs                     # プラグインエラー定義
├── guest-js/
│   ├── index.ts                     # パッケージエクスポート
│   ├── types.ts                     # SettingTabPlugin, SettingTabProps
│   ├── SettingsRegistry.ts          # タブ登録・管理ハブ
│   ├── SettingsContext.tsx          # useSettings, SettingsProvider (IPC連携)
│   ├── SettingsModal.tsx            # 共通設定モーダルUI
│   └── SettingsModal.css            # テーマ連動スタイル
├── package.json                     # "name": "restar-app-settings"
├── tsconfig.json
└── rollup.config.js                 # dist-js へのRollupバンドル
```

---

## 3. Rust実装仕様

### `src/commands.rs`
- `load_settings<R: Runtime>(app: AppHandle<R>) -> Result<serde_json::Value, String>`
- `save_settings<R: Runtime>(app: AppHandle<R>, settings: serde_json::Value) -> Result<(), String>`
- `get_settings_path<R: Runtime>(app: AppHandle<R>) -> Result<String, String>`

設定ファイルの保存先は、Tauriの `app.path().app_config_dir()` 配下の `settings.json` とします。

---

## 4. ホストアプリ（`novelaide`）との接続

- `package.json`: `"restar-app-settings": "file:tauri-plugin-restar-settings"`
- `src-tauri/Cargo.toml`: `tauri-plugin-restar-settings = { path = "../tauri-plugin-restar-settings" }`
- `src-tauri/src/lib.rs`: `.plugin(tauri_plugin_restar_settings::init())`
- `src-tauri/capabilities/default.json`: `"restar-settings:default"`
