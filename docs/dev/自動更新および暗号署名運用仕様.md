# 自動更新および暗号署名運用仕様

## 1. 概要

本仕様書は、小説執筆デスクトップIDE `novelaide` における Tauri v2 公式の自動更新機能（`tauri-plugin-updater` / `tauri-plugin-process`）および暗号署名（Minisign / Ed25519）の運用手順、システム設計を定義するものです。

### 目的
- GitHub Releases（`mituha/novelaide`）と連携し、インストーラーの再ダウンロード・再インストールを手動で行うことなく、アプリ内から安全かつワンクリックで最新版へ更新できるようにします。
- 小説執筆作業を妨げないよう、更新確認はサイレントに実行され、ダウンロード・適用・再起動はすべてユーザーの意思によって制御される安全設計を徹底します。
- 改ざん防止のため、バイナリ署名検証を必須とします。

---

## 2. アーキテクチャと署名メカニズム

```
[開発・ビルド環境 / GitHub Actions]
   │
   ├─ npm run release (タグ push: v*)
   │     │
   │     ▼
   │  GitHub Actions (.github/workflows/release.yml)
   │     │
   │     ├─ tauri build --bundles nsis
   │     │  (TAURI_SIGNING_PRIVATE_KEY & PASSWORD により署名)
   │     │
   │     ▼
   │  GitHub Releases (Published)
   │     ├─ novelaide_x.x.x_x64-setup.exe
   │     ├─ novelaide_x.x.x_x64-setup.nsis.zip (Updater用アセット)
   │     ├─ novelaide_x.x.x_x64-setup.nsis.zip.sig (署名ファイル)
   │     └─ latest.json (マニフェスト)
   │
[エンドユーザー / novelaide アプリ]
   │
   ├─ 起動時バックグラウンド確認 (10秒後) / 設定画面での手動確認
   │     │
   │     ▼
   │  latest.json を取得し、現在のバージョンと比較
   │     │
   │     ├─ 更新ありの場合
   │     ▼
   │  トースト通知または更新ダイアログを表示
   │     │ (ユーザーが「更新」を承認)
   │     ▼
   │  nsis.zip をダウンロード ──▶ 内蔵公開鍵 (pubkey) で .sig を検証
   │     │ (検証成功)
   │     ▼
   │  アップデート適用 ──▶ relaunch() による最新版再起動
```

## 3. 鍵管理と GitHub Actions 連携仕様

### 3.1 暗号署名キーペア
- **方式**: Minisign / Ed25519
- **鍵生成コマンド**:
  ```bash
  npx @tauri-apps/cli signer generate -w $HOME/.tauri/novelaide.key
  ```

### 3.2 秘密鍵（Private Key）の保管
- **保管場所**: GitHub リポジトリ（`mituha/novelaide`）の Repository Secrets
  - `TAURI_SIGNING_PRIVATE_KEY`: 秘密鍵ファイルの内容（パスワードで暗号化された Minisign 秘密鍵）
  - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`: 秘密鍵の復号用パスワード
- **セキュリティ方針**:
  - 秘密鍵およびパスワードはリポジトリのソースコード、コミット履歴、イシュー等に絶対に含めない。

### 3.3 公開鍵（Public Key）の配置
- **配置場所**: `src-tauri/tauri.conf.json`
  - `plugins.updater.pubkey`: 生成された公開鍵文字列（`dW50cnVzdGVk...`）を設定。
  - 公開鍵は暗号学的に安全な公開情報であり、バイナリ改ざん検証にのみ用いられます。

## 4. Tauri 設定仕様

### 4.1 `src-tauri/tauri.conf.json`
```jsonc
{
  "bundle": {
    "createUpdaterArtifacts": true // Updater用アーカイブ(.zip)および署名(.sig)の生成を有効化
  },
  "plugins": {
    "updater": {
      "pubkey": "<MINISIGN_PUBLIC_KEY_STRING>",
      "endpoints": [
        "https://github.com/mituha/novelaide/releases/latest/download/latest.json"
      ]
    }
  }
}
```

### 4.2 権限設定（`src-tauri/capabilities/default.json`）
```jsonc
{
  "permissions": [
    "core:default",
    // ...
    "updater:default",
    "process:default"
  ]
}
```

## 5. UI / UX 仕様

### 5.1 起動時の自動チェック
- **タイミング**: アプリ起動完了後、10〜15秒の待機時間を設けてから非同期で実行（起動時パフォーマンス優先）。
- **ユーザー設定**: 設定モーダル内の「起動時に自動で更新を確認する」（デフォルト: ON）で無効化可能。
- **挙動**:
  - 最新版の場合、またはオフライン・通信エラー時は**完全にサイレント**（ダイアログやトーストは表示しない）。
  - 新バージョンが検出された場合のみ、画面右下に控えめなトーストを表示:
    > **novelaide vX.X.X が利用可能です**  
    > [詳細を確認 / 更新]

### 5.2 設定モーダル（全般タブ）
- `restar-app-settings` に「全般（General）」タブを新設。
- **表示項目**:
  - アプリケーション名および現在のバージョン（例: `novelaide v0.55.0`）
  - 「起動時に自動で更新を確認する」チェックボックス
  - 「更新を確認」ボタン
- **手動確認時のフィードバック**:
  - チェック中: スピナーアイコン
  - 最新の場合: 「現在最新バージョン（vX.X.X）をご利用中です」
  - 更新がある場合: 更新内容モーダルを直接起動

### 5.3 アップデート進捗および再起動ダイアログ
- **ダウンロード中**:
  - プログレスバー（受信済みバイト数 / 総容量、またはパーセント表示）。
  - 「ダウンロード中... しばらくお待ちください（執筆作業はそのまま続けられます）」
- **インストール準備完了時**:
  - 「アップデートの準備が完了しました。最新バージョンを適用して再起動しますか？」
  - **[今すぐ再起動]**: `relaunch()` を実行しアプリを再起動。
  - **[後で]**: ダイアログを閉じ、次回アプリ起動時に最新版が反映される。

## 6. CI/CD リリースワークフロー仕様

`.github/workflows/release.yml` において、`tauri-apps/tauri-action` に署名鍵シークレットを渡します。

```yaml
      - name: Build Tauri app and create GitHub Release
        uses: tauri-apps/tauri-action@v0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY }}
          TAURI_SIGNING_PRIVATE_KEY_PASSWORD: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY_PASSWORD }}
        with:
          tagName: v__VERSION__
          releaseName: 'novelaide v__VERSION__'
          releaseDraft: false
          prerelease: false
```

- タグ（例: `v0.55.0`）がプッシュされると、GitHub Actions ランナー上で Windows 向け NSIS インストーラーと Updater 用 zip・sig、`latest.json` が自動生成され、GitHub Release に即時本公開されます。
