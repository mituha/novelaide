# エディタータブのスクロールおよびオーバーフロー制御仕様

## 1. 概要

`novelaide` のマルチタブエディターにおいて、多数のドキュメントを開いた際にタブヘッダーがコンテナを突き破って隠れたり、右端のアクションボタン群（分割・プレビュー切替など）が押し出されてしまう問題を解決するための仕様です。

旧Electron版（`novelaid-editor`）のホイール水平スクロールおよびタブ一覧ドロップダウンの良さを継承しつつ、VS Code等のモダンエディタにおける自動スクロールイン（`scrollIntoView`）と堅牢なFlexboxオーバーフロー制御を組み合わせて実装されています。

---

## 2. アーキテクチャとレイアウト設計

### 2.1 Flexbox による領域分離と突き破り防止

タブバー（`.editor-tabs-bar`）は、以下の3領域に明確に分離されます。

```text
+-----------------------------------------------------------------------------------------+
| [v] | [Tab 1] [Tab 2] ... [Tab N] (水平スクロール可能)       | [表示] [横に分割] [分割プレビュー] |
+-----------------------------------------------------------------------------------------+
 (1)        (2) tabsListRef / flex: 1, min-width: 0                 (3) flex-shrink: 0, margin-left: auto
```

1. **ドロップダウンボタン領域（`.editor-tabs-dropdown-container`）**:
   - `flex-shrink: 0`
   - 開いている全タブを縦並びリストでポップオーバー表示する `ChevronDown` ボタン。
2. **スクロール可能タブ領域（`.editor-tabs-list`）**:
   - `flex: 1; min-width: 0;`（Flexboxのコンテンツ突き破りを完全に防止）
   - `overflow-x: auto; overflow-y: hidden;`
   - `scrollbar-width: none;`（スクロールバーを非表示にし、ホイール操作に特化）
3. **右端アクションボタン領域（`.editor-tabs-actions`）**:
   - `flex-shrink: 0; margin-left: auto;`
   - タブ数に関わらず画面右端に確実に固定され、絶対に隠れない。

### 2.2 タブアイテムのサイジングルール

* `.editor-tab-item`:
  - `flex-shrink: 0;`（タブ幅が自動的に潰れてアイコンやタイトルが押し潰されるのを防止）
  - `min-width: 100px; max-width: 200px;`
  - `.tab-title`: `overflow: hidden; text-overflow: ellipsis; white-space: nowrap; flex: 1;`（長文ファイル名は末尾「...」で省略）

## 3. 操作仕様

### 3.1 通常マウスホイールによる水平スクロール
タブバー上でマウスホイールを上下に回す（`deltaY`）だけで、水平スクロール（`scrollLeft`）に変換されます。
トラックパッドによる水平ジェスチャー（`deltaX`）にも両対応しています。

```typescript
const handleWheel = (e: React.WheelEvent<HTMLDivElement>) => {
  if (tabsListRef.current) {
    const delta = Math.abs(e.deltaX) > Math.abs(e.deltaY) ? e.deltaX : e.deltaY;
    if (delta !== 0) {
      tabsListRef.current.scrollLeft += delta;
    }
  }
};
```

### 3.2 アクティブタブの自動スクロールイン（Auto Scroll Into View）
エクスプローラーからのファイル選択、エピソード前後移動、検索ジャンプなどにより、現在画面外に隠れているタブがアクティブになった場合、自動的に可視範囲へスムーズスクロールします。

```typescript
useEffect(() => {
  if (!activePath || !tabsListRef.current) return;
  const activeElem = tabsListRef.current.querySelector<HTMLElement>('.editor-tab-item.active');
  if (activeElem) {
    activeElem.scrollIntoView({
      behavior: 'smooth',
      block: 'nearest',
      inline: 'nearest',
    });
  }
}, [activePath]);
```

### 3.3 開いているタブ一覧ドロップダウンメニュー
* タブバー左端の `ChevronDown` ボタンをクリックすると、現在ペインで開いているタブのリストがポップオーバー表示されます。
* リストには、ドキュメント種別アイコン、ファイル名、未保存インジケーター（赤丸）、閉じるボタン（×）が表示されます。
* タブをクリックすると即座にアクティブ化され、メニューが閉じます。
* メニューの外側をクリックすると自動的に閉じます（外側クリック検知リスナー）。
