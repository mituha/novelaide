# メタデータリストパネル実装仕様（`BaseMetadataListPanel` 基盤）

## 1. 概要とアーキテクチャ

本ドキュメントは、**`novelaide`** において、プロジェクト全域のドキュメントから YAML Frontmatter メタデータを収集・分類し、サイドペインで一覧表示・検索・クイックアクセスを提供するパネル群のプログラム実装仕様を定義するものである。

> [!IMPORTANT]
> **共通仕様・UI概念の参照元**:
> - 純粋なファイルフォーマット規約およびコア項目定義: [Frontmatterメタデータ共通仕様](../../novelaid-editor-docs/docs/dev/Frontmatterメタデータ仕様.md)
> - メタデータリストパネルのUI概念・分類要件: [メタデータリストパネル仕様](../../novelaid-editor-docs/docs/dev/メタデータリストパネル仕様.md)

本実装は、共通基盤コンポーネント **`BaseMetadataListPanel`** を導入し、重複のない疎結合なプラグイン設計によって独立した4つのトップレベルパネルを提供している。

---

## 2. パネル一覧とプラグイン構成

| パネル識別子 | パネル名称 | アイコン | 対象メタデータタグ・条件 |
| :--- | :--- | :--- | :--- |
| **`novelaid.panel.characters`** | 👤 登場人物 | `Users` | `character`, `登場人物`, `人物`, `chara` 等。<br>`role`（主人公、サブ、敵対、その他）別に自動分類。 |
| **`novelaid.panel.locations`** | 📍 地名・施設 | `MapPin` | `location`, `places`, `place`, `地名`, `施設`, `場所`, `舞台`, `世界観`, `拠点`, `国`, `都市` 等。 |
| **`novelaid.panel.plots`** | 📜 プロット・構成 | `FileText` | `plot`, `構成`, `案`, `timeline`, `時間軸`, `年表`, `章`, `エピソード` 等。<br>巻・本別、章別に分類。 |
| **`novelaid.panel.metadataList`** | 🔖 設定資料総合 | `Tags` | 全設定資料ドキュメントの横断閲覧・検索。 |

## 3. コンポーネント実装詳細

### 3.1 対象ソースコード
- **基底共通コンポーネント**: `src/components/Metadata/BaseMetadataListPanel.tsx`
- **各パネル定義**:
  - `src/components/Metadata/CharacterListPanel.tsx`
  - `src/components/Metadata/LocationListPanel.tsx`
  - `src/components/Metadata/PlotListPanel.tsx`
  - `src/components/Metadata/MetadataListPanel.tsx`

### 3.2 共通機能とインタラクションロジック

1. **シリーズ・巻フィルタリング**:
   - `series` および `books` プロパティに基づく階層セレクトボックス。
2. **複数タグ AND 絞り込み**:
   - 選択されたすべてのタグを含むアイテムのみを抽出するフィルタリング。
3. **インクリメンタル検索**:
   - `title`, `name`, `reading`, `description`, `tags` を横断したリアルタイム絞り込み。
4. **エディター連携（クリックオープン & DnD）**:
   - アイテムクリックで `documentContext.openDocument(item.path)` を呼び出し、該当ファイルを即座に開く。
   - アイテムのドラッグ操作により、エディター本文への名前・ルビ挿入をサポート。
5. **アコーディオン領域の自動按分と個別スクロール**:
   - 複数セクション展開時にもパネル全体が破綻しないよう、アコーディオン個別スクロールおよびリサイズ境界を保持。
