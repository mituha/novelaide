# アプリアイコン作成およびアセット仕様書

## 1. 概要

本ドキュメントは、**`novelaide`** におけるデスクトップアプリアイコン、Webファビコン、および関連アセットの作成手順、配置構成、生成パイプラインについての仕様を定義するものです。

---

## 2. アセットの配置構成

リポジトリ内のアイコンおよび画像アセットは、以下の役割分担で管理されています。

```text
novelaide/
├── assets/                         # アプリケーション共通のマスターアセット（高解像度）
│   ├── 1024x1024.png               # マスター正方形PNG（Tauriアイコン自動生成用、透過あり）
│   ├── icon.png                    # 代表PNGアイコン (512x512)
│   ├── icon.ico                    # Windows用アイコンリソース
│   └── icon.icns                   # macOS用アイコンリソース
│
├── public/                         # フロントエンド静的配信ディレクトリ
│   ├── icon.png                    # Webファビコン用PNG
│   └── favicon.ico                 # Webファビコン用ICO
│   （※初期テンプレートの tauri.svg, vite.svg はクリーンアップ済み）
│
└── src-tauri/
    ├── tauri.conf.json             # バンドル設定（icons指定、バージョン定義）
    └── icons/                      # Tauri CLI により自動生成された全解像度アイコン
        ├── 32x32.png
        ├── 64x64.png
        ├── 128x128.png
        ├── 128x128@2x.png
        ├── icon.ico                # WindowsインストーラーおよびEXE用
        ├── icon.icns               # macOS App Bundle用
        ├── Square...Logo.png       # Windows Store / AppX 各種サイズ
        └── StoreLogo.png
```

---

## 3. アイコン自動生成パイプライン (`tauri icon`)

Tauri 2.x では、1枚の高解像度マスター画像（1024x1024の透過PNG）から、全プラットフォーム向けのマルチサイズアイコンを一括生成するCLI機能が標準提供されています。

### 3.1 生成コマンド

```pwsh
# novelaide ルートディレクトリにて実行
npx tauri icon assets/1024x1024.png
```

### 3.2 自動生成される出力アセット
このコマンドを実行すると、`src-tauri/tauri.conf.json` の設定に合わせて以下のファイルが `src-tauri/icons/` 配下に完全自動生成・更新されます：

* **Windows 用**:
  - `icon.ico`（16x16 〜 256x256 のマルチサイズ埋め込みICO）
  - 各種タイルスケーリング用（`Square44x44Logo.png`, `Square150x150Logo.png`, `StoreLogo.png` 等）
* **macOS 用**:
  - `icon.icns`（Retinaディスプレイ対応 Apple Icon Image）
* **Linux / Web 用**:
  - `32x32.png`, `64x64.png`, `128x128.png`, `128x128@2x.png`, `icon.png`

## 4. フロントエンドおよびバンドル設定

### 4.1 `index.html` でのファビコン設定

ブラウザウィンドウやWebViewのタイトルバー用に、`public/` 配下のアイコンをリンクします。

```html
<link rel="icon" type="image/png" href="/icon.png" />
<link rel="alternate icon" href="/favicon.ico" />
```

### 4.2 `src-tauri/tauri.conf.json` での参照設定

```json
{
  "productName": "novelaide",
  "version": "0.18.9",
  "bundle": {
    "icon": [
      "icons/32x32.png",
      "icons/128x128.png",
      "icons/128x128@2x.png",
      "icons/icon.icns",
      "icons/icon.ico"
    ]
  }
}
```
