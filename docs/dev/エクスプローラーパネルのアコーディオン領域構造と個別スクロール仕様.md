# エクスプローラーパネルのアコーディオン領域構造と個別スクロール仕様

## 1. 概要と背景

本仕様は、サイドバーのエクスプローラーパネルにおいて、多数のファイルや項目が存在する場合にパネル全体がスクロールしてしまい、ヘッダー（「開いているドキュメント」「ワークスペース」「見出しアウトライン」等）が画面外へ流れてしまう問題を解決するための領域構造設計です。

VS Codeなどの現代的なIDEと同様に、各セクションの開閉（アコーディオン）状態に応じて動的に領域を按分し、各セクション内部でのみ独立してスクロールする構造を実現します。

また、本エクスプローラーパネルでの実装と動作確認完了後、検索パネル・Git管理パネル・メタデータパネル等の他パネルにも同様の領域按分・個別スクロール方針を水平展開します。

---

## 2. 領域配分とアコーディオン動作設計

### 2.1 セクション状態とFlexbox動作

| 状態 | セクションラッパーのCSS | 挙動説明 |
| :--- | :--- | :--- |
| **折りたたみ（Collapsed）** | `flex: 0 0 auto;` | ヘッダー高さ（28px）のみを固定占有。リサイズスプリッターは非表示。 |
| **単一セクション展開** | `flex: 1 1 0; min-height: 48px;` | 残りの空き領域を100%占有して画面下部まで広がる。 |
| **複数セクション展開** | `flex: ${weight} 1 0; min-height: 48px;` | 各セクションの `weight`（初期値 1:1:...）に応じて残り領域を按分。境界リサイズ可能。 |
| **全セクション折りたたみ** | 全て `flex: 0 0 auto;` | 上部にヘッダーがスタック整列し、下部に空き余白が形成される。 |

### 2.2 セクション境界リサイズスプリッター（ドラッグハンドル）

* 展開されているセクション同士の間に、高さ4pxのマージン相殺型リサイザー（`.explorer-section-resizer`）を配置。
* ドラッグ操作（`onMouseDown` → `onMouseMove` → `onMouseUp`）により、上下セクションの現在ピクセル高さを基準として `weight` 比率を動的に更新。
* 最小高さ（`minHeight: 48px`）の制約を設け、セクションが不可視状態まで押し潰されることを防止。

## 3. コンポーネントおよびスタイル構造

### 3.1 `ExplorerPanel.tsx` / `ExplorerPanel.css`

* **`.explorer-panel-container`**:
  - `overflow: hidden; height: 100%; display: flex; flex-direction: column;`
  - パネルコンテナ自体は固定高さとし、親からのスクロールを完全遮断。
* **`.explorer-section-wrapper`**:
  - `collapsed`: `flex: 0 0 auto;`
  - `expanded`: `min-height: 48px; overflow: hidden; display: flex; flex-direction: column;`
* **`.explorer-section-body.expanded`**:
  - `flex: 1; min-height: 0; overflow-y: auto; overflow-x: hidden; display: flex; flex-direction: column;`
  - 子コンポーネントの高さが枠を超えた場合、このボディ内部でのみ縦スクロールバーが表示される。

### 3.2 子セクションの適応

* **ファイルツリーセクション（`FileTreeSection` / `FileExplorer`）**:
  - ラッパーに `height: 100%; display: flex; flex-direction: column; min-height: 0;` を付与し、内部の `.explorer-tree-container` に高さを確実に伝播。
* **開いているドキュメント（`OpenDocumentsSection`）**:
  - `.open-docs-section-list` に `overflow-y: auto; overflow-x: hidden; flex: 1; min-height: 0;` を追加し、多数のファイルが開かれていてもセクション内で独立スクロール。
* **見出しアウトライン（`OutlineSection` / `DocumentOutline`）**:
  - ラッパーに `height: 100%; min-height: 0;` を適用し、既存の `.document-outline-list` の個別スクロールを有効化。

## 4. 他パネルへの水平展開と実装実績

エクスプローラーパネルで確立した「Flexbox自動按分・内部個別スクロール・境界リサイズハンドル」アーキテクチャを、内部に複数のアコーディオンセクションを持つ主要パネルへ水平展開しました。

### 4.1 Gitソース管理パネル（`GitPanel.tsx` / `GitPanel.css`）

* **対象セクション**:
  1. `staged`（STAGED CHANGES: ステージ済み変更ファイル一覧）
  2. `changes`（CHANGES: 未ステージ・未追跡ファイル一覧）
  3. `history`（COMMIT HISTORY: コミット履歴グラフおよびメッセージリスト）
* **構造改修**:
  - `.git-panel-body` の `overflow-y: auto` を廃止し、`flex: 1; min-height: 0; overflow: hidden; display: flex; flex-direction: column;` に変更。
  - セクション開閉に応じ、折りたたみ時は `flex: 0 0 auto`、展開時は `flex: ${weights[id]} 1 0px` で動的に領域按分。
  - `.git-section-list` および `.git-history-container` に `flex: 1; min-height: 0; overflow-y: auto; overflow-x: hidden;` を適用し、ファイル数やコミット数が多い場合でもセクション枠内だけで独立スクロール。
  - 展開セクション間に `.git-section-resizer` を配置し、境界ドラッグリサイズに対応。

### 4.2 共通メタデータ一覧パネル（`BaseMetadataListPanel.tsx` / `BaseMetadataListPanel.css`）

* **対象パネル群**:
  - `MetadataListPanel`（全メタデータ一覧）
  - `CharactersPanel`（登場人物パネル）
  - `LocationsPanel`（地名・舞台パネル）
  - `PlotsPanel`（プロット・年表パネル）
* **構造改修**:
  - `.base-metadata-body` の `overflow-y: auto` を廃止し、`flex: 1; min-height: 0; overflow: hidden; display: flex; flex-direction: column;` に変更。
  - 各グループ（カテゴリ別、巻別、役割別、タグ別など）の開閉に応じ、折りたたみ時は `flex: 0 0 auto`、展開時は `flex: ${weights[groupKey]} 1 0px` で按分。
  - `.base-metadata-items` に `flex: 1; min-height: 0; overflow-y: auto; overflow-x: hidden;` を適用し、カードが多数あってもグループ枠内だけでスクロール。
  - 隣接する展開グループ間に `.base-metadata-group-resizer` を配置し、上下境界のドラッグリサイズに対応。
