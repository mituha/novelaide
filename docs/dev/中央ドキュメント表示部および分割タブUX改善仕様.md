# 中央ドキュメント表示部および分割タブUX改善仕様

## 1. 概要

`novelaide` の中央ドキュメント表示部（エディター領域）において、左右分割表示時の利便性向上、タブバーの表示領域最大化、直感的な分割・クローズ操作、およびアクティブタブの視認性強化を目的とした改修仕様です。

---

## 2. 仕様詳細

### 2.1 右ペイン全タブクローズ時の自動分割解除
* **動作仕様**:
  - 左右分割表示中（`isSplit === true`）に、右ペイン（`editor.right`）の最後のタブを閉じた場合、自動的に `isSplit` を `false` に変更し、右ペインを閉じて左ペイン単一の全幅表示へ復帰します。
  - 「タブが開かれていません」という空の領域が残る不自然さを解消しました。
* **実装箇所**: `src/contexts/DocumentContext.tsx` 内の `closeTab`
  - `hasLeft && !hasRight`（左にタブがあり、右のタブが0件になった）を検知し、`setIsSplit(false)`、`setActivePane('editor.left')`、`'editor.right': null` を実行。

### 2.2 左右分割表示時のアクションボタン省スペース化
* **動作仕様**:
  - 左右分割表示中（`isSplit === true`）は、タブバー右端のアクションボタン（表示/編集切替、分割など）のラベルテキスト（`<span>`）を非表示にし、アイコンのみの表示（パディングもスリム化）とします。
  - これにより、2画面分割で狭くなりがちなタブ一覧の表示領域を最大限に確保します。
  - マウスホバー時のツールチップ（`title` 属性）は維持され、機能名はいつでも確認できます。

### 2.3 右画面のアクション整理とタブコンテキストメニュー
* **アクションボタンの配置整理**:
  - 右ペイン（`paneId === 'editor.right'`）のアクションエリアからは、ユーザーの誤解を招く「横に分割」「分割プレビュー」ボタンを撤去。
  - 右ペインには「表示/編集切替」および「ペインを閉じる」のみを配置します。
* **タブコンテキストメニュー（右クリックメニュー）の新設**:
  - タブアイテムを右クリックした際、以下のメニューをポップアップ表示します：
    1. **閉じる**: 当該タブを閉じる
    2. **他のタブを閉じる**: 当該タブ以外の同ペインのタブを一括クローズ
    3. **右側のタブを閉じる**: 当該タブより右側にあるタブを一括クローズ
    4. **すべてのタブを閉じる**: 同ペインの全タブを一括クローズ
    5. *(セパレーター)*
    6. **横に分割して開く**: 反対ペインに当該ドキュメントを分割表示
    7. **分割プレビューで開く**: 小説/Markdownドキュメントの場合、反対ペインにプレビューとして開く
    8. **右ペインを閉じる**: 右ペイン分割時のみ表示
  - メニュー外クリックまたは `Escape` キーで自動クローズします。

### 2.4 アクティブタブの視認性強化（フォルダータブデザイン）
* **動作仕様**:
  - アクティブなタブ（`.editor-tab-item.active`）の上端にアクセントカラー（`var(--accent-color)`）の2pxラインを配置。
  - 左右に明確な境界線（`border-left`, `border-right`）を設け、下端はエディタ本文の背景色（`var(--bg-primary)`）とシームレスに結合。
  - 未保存の変更があるアクティブタブは、上端ラインが鮮やかな赤色（`#ef4444`）に変化し、保存状態が直感的に把握できます。
