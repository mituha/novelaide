# 文章校正と文体解析の使い方

`novelaide` には、小説執筆に特化した日本語文章校正・文体解析機能（`Calibration`）が備わっています。
外部のLLMやクラウド通信に依存せず、ローカル環境で高速・安全に動作し、原稿のクオリティ向上を支援します。

---

## 1. 校正・解析パネルの開き方

1. 画面右側（または左側）のアクティビティバーにある「**校正・解析**」アイコン（チェックマーク付きの書類アイコン）をクリックします。
2. サイドパネルに「文章校正・文体解析」パネルが表示されます。
3. エディタで開いているアクティブな原稿ファイルが自動的に検証対象となります。
4. 原稿の編集中や更新後に内容を再スキャンしたい場合は、パネル上部の「**再検証**」ボタンをクリックします。

---

## 2. パネルの機能構成

パネル内には、用途に応じた3つのタブが用意されています。

### 2.1. 「指摘一覧」タブ（文章校正）

執筆中の文章から、小説の作法違反や不自然な文法、ら抜き言葉、二重否定、助詞の連続、漢字の開き忘れなどを自動検知してカード形式で一覧表示します。

* **主な指摘カテゴリと対応ルール**:
  - **小説作法・文字種（novel_style）**:
    - **半角空白禁止**: 小説執筆では半角空白を使わず全角空白に統一するルール（自動置換対応）
    - **全角パイプ禁止**: ルビ記法開始記号として半角パイプ `|` を使用し、全角パイプ `｜` は禁止（自動置換対応）
    - **会話文末の句点**: かぎ括弧直前の不要な句点（「〜〜。」）の検出・除去（自動置換対応）
    - **連続句読点の禁止**: `。。` や `、、` などのタイポ・句読点重複の検出と1文字への修正提案（自動置換対応）
    - **行頭禁則記号の検知**: 行の先頭に配置された句読点（`、` `。`）や閉じ括弧（`」` `）` 等）、音引きなどの行頭禁則違反の検出
    - **三点リーダー2マス**: 単独の「…」や奇数個の連続を検出し偶数マス「……」への修正を提案（自動置換対応）
    - **ダッシュ2マス**: 単独の「―」や奇数個の連続を検出し偶数マス「――」への修正を提案（自動置換対応）
    - **括弧直前の不要な空白**: かぎ括弧直前の余分な空白（「〜〜　」）の検出・除去（自動置換対応）
    - **対応する括弧の未閉じ・不整合検知**: 括弧の閉じ忘れ、開きのない閉じ括弧、異なる種類の括弧で閉じている構文エラーの検出（修正候補提示）
    - **感嘆符・疑問符後の全角空白**: 文中感嘆符（`！` `？`）の直後に文字が続く場合の全角1マス空け要求（自動置換対応）
    - **感嘆符・疑問符の全角正規化**: 半角の `!` `?` `!?` などの混入を検知し全角への正規化を提案（自動置換対応）
  - **構造・段落（novel_structure / novel_style）**:
    - **段落冒頭の字下げ**: 会話括弧や見出し以外の地の文行頭での全角1マス字下げ要求（`❤〚` や `◆［` などのアイコン1文字＋開き括弧行、および `――` ダッシュ演出行は免除、自動置換対応）
    - **文末助動詞の連続重複**: 「〜た。〜た。〜た。」など、同一の助動詞文末（過去形「た/だ」、丁寧語「です/ます」等）が3文以上連続した単調リズムの検知・注意喚起（パラメータ調整可能）
  - **文法・語彙（grammar）**:
    - **ら抜き言葉検知**: 「見れる（見られる）」「食べれる（食べられる）」「来れる（来られる）」等のら抜き表現の検出（修正候補提示）
    - **二重否定検知**: 「〜ないわけではない」「〜なくもない」「〜ないでもない」など回りくどい表現の注意喚起
    - **助詞の連続・多用**: 一文中での助詞「の」の3回以上連続、および助詞「が」の3回以上の多用警告（パラメータ調整可能）
  - **表記・開き（kanji_open_close）**:
    - **漢字の開き**: 形式名詞（「事→こと」「時→とき」「所→ところ」「物→もの」等）の平仮名開き推奨（自動置換対応）
* **操作とエディタ連動**:
  - **エディタ上の波線ハイライト**: 指摘が検出されると、エディタ本文の該当位置に自動的に波線（警告・情報）が表示され、マウスを合わせると指摘内容がツールチップで確認できます。
  - **該当位置へのジャンプ**: 指摘カードをクリックすると、エディタの該当行・列にスクロールし、対象テキストが自動選択されます。
  - **[適用] ボタン**: 指摘された修正候補（例: 半角空白の全角置換、「事」を「こと」に置換等）をワンクリックでエディタ本文に即時反映します。
  - **[AI] ボタン**: AI執筆パートナーと連携し、指摘箇所を自然にリライトするための推敲相談を呼び出します（準備中）。

---

### 2.2. 「文体・比率」タブ（漢字比率と頻出語）

小説の読みやすさを左右する文字種比率や、頻出語句を可視化します。

* **漢字・ひらがな比率ゲージ**:
  - 本文中の全文字数、漢字比率（%）、ひらがな比率（%）をリアルタイムに計算してプログレスバーで表示します。
  - 一般的に読みやすいとされる小説の黄金比（漢字 20%〜30%、ひらがな 70%前後）の目安と比較できます。
* **頻出語ランキング**:
  - 本文で多用されている名詞や動詞などの単語を出現回数順に一覧表示します。
  - 特定の単語や表現の重複・偏りを客観的に把握するのに役立ちます。

---

### 2.3. 「ルビ支援」タブ（ルビ付け候補）

本文中の人名や難読漢字を検出し、青空文庫形式のルビを付与するための支援機能です。

* **ルビ候補の確認**:
  - 本文からルビ推奨語句（例: `神代玲央` → `かみしろれお`）を自動抽出します。
* **[挿入] ボタン**:
  - クリックすると、エディタの該当箇所が `｜神代玲央《かみしろれお》` の青空文庫記法に瞬時に変換・挿入されます。
