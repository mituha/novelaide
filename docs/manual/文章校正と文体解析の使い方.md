# 文章校正と文体解析の使い方

`novelaide` には、小説執筆に特化した日本語文章校正・文体解析機能（`Calibration`）が備わっています。
外部のLLMやクラウド通信に依存せず、ローカル環境で高速・安全に動作し、原稿のクオリティ向上を支援します。

---

## 1. 校正・解析パネルの開き方

1. 画面右側（または左側）のアクティビティバーにある「**校正・解析**」アイコン（チェックマーク付きの書類アイコン）をクリックします。
2. サイドパネルに「文章校正・文体解析」パネルが表示されます。
3. エディタで開いているアクティブな原稿ファイルが自動的に検証対象となります。
4. 原稿の編集中や更新後に内容を再スキャンしたい場合は、パネル上部の「**再検証**」ボタンをクリックします。

---

## 2. パネルの機能構成

パネル内には、用途に応じた3つのタブが用意されています。

### 2.1. 「指摘一覧」タブ（文章校正）

執筆中の文章から、小説の作法違反や不自然な助詞の連続、漢字の開き忘れなどを自動検知してカード形式で一覧表示します。

* **主な指摘カテゴリ**:
  - **作法（novel_style）**:
    - 会話文末のかぎ括弧直前にある不要な句点（「〜〜。」）の検出
    - 三点リーダーの奇数個使用（「…」→「……」）の注意喚起
  - **開き（kanji_open_close）**:
    - 形式名詞（「事」→「こと」など）の平仮名開き推奨
  - **助詞（particle_repetition）**:
    - 同一行内での助詞「の」の3回以上重複警告
* **操作ボタン**:
  - **[適用] ボタン**: 指摘された修正候補（例: 「事」を「こと」に置換）をワンクリックでエディタ本文に即時反映します。
  - **[AI] ボタン**: AI執筆パートナーと連携し、指摘箇所を自然にリライトするための推敲相談を呼び出します（準備中）。

---

### 2.2. 「文体・比率」タブ（漢字比率と頻出語）

小説の読みやすさを左右する文字種比率や、頻出語句を可視化します。

* **漢字・ひらがな比率ゲージ**:
  - 本文中の全文字数、漢字比率（%）、ひらがな比率（%）をリアルタイムに計算してプログレスバーで表示します。
  - 一般的に読みやすいとされる小説の黄金比（漢字 20%〜30%、ひらがな 70%前後）の目安と比較できます。
* **頻出語ランキング**:
  - 本文で多用されている名詞や動詞などの単語を出現回数順に一覧表示します。
  - 特定の単語や表現の重複・偏りを客観的に把握するのに役立ちます。

---

### 2.3. 「ルビ支援」タブ（ルビ付け候補）

本文中の人名や難読漢字を検出し、青空文庫形式のルビを付与するための支援機能です。

* **ルビ候補の確認**:
  - 本文からルビ推奨語句（例: `神代玲央` → `かみしろれお`）を自動抽出します。
* **[挿入] ボタン**:
  - クリックすると、エディタの該当箇所が `｜神代玲央《かみしろれお》` の青空文庫記法に瞬時に変換・挿入されます。
