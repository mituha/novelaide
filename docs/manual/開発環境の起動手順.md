# 開発環境の起動手順

本ドキュメントでは、小説執筆エディター **`novelaide`** の開発環境をローカルで起動・動作確認する手順を説明します。

---

## 1. 前提条件

以下のランタイムがマシンにインストールされている必要があります。

* **Node.js**: v20以上推奨（npm 10以上）
* **Rust**: 1.80以上（cargo / rustc）
* **C++ ビルドツール**:
  * Windows: Visual Studio C++ ビルドツール（MSVC）
  * macOS: Xcode Command Line Tools
  * Linux: `build-essential`, `libwebkit2gtk-4.1-dev` 等

---

## 2. セットアップ手順

### 2.1 パッケージのインストール
リポジトリ直下で依存関係をインストールします。

```bash
npm install
```

### 2.2 開発モードでの起動（デスクトップアプリ）
Vite開発サーバーとTauriウィンドウを同時に立ち上げます。

```bash
npm run tauri dev
```

起動後、1024×768のデスクトップウィンドウが表示され、HMR（Hot Module Replacement）によるリアルタイムなコード反映が有効になります。

### 2.3 フロントエンド単体でのビルド確認
```bash
npm run build
```

### 2.4 バックエンド（Rust）のチェック
```bash
cd src-tauri
cargo check
```
