# バッチ処理ツールの使い方

本ドキュメントでは、小説執筆エディター **`novelaide`** における **バッチ処理ツール（`BatchToolsPanel`）** を使って、複数ファイルの拡張子を一括変更する手順について説明します。

---

## 1. ツールパネルの開き方

1. 画面右側のアクティビティバーにある **スパナアイコン（ツール）** をクリックします。
2. 右ペインに **「バッチツール」** パネルが開きます。
   - 左側のファイルエクスプローラーを見ながら、右側で並行して安全に操作できます。

---

## 2. 一括拡張子変更（.md ⇔ .txt）の手順

### ステップ 1: 対象フォルダーの選択
- パネル中央の **「対象フォルダー」** ドロップダウンから、変更したいフォルダー（プロジェクト全体、または特定の章フォルダー）を選択します。
- **ドラッグ＆ドロップ（D&D）での指定**:
  - 左ペインのファイルエクスプローラーにあるフォルダーを、対象フォルダー欄へ直接ドラッグ＆ドロップすることでも選択できます。
  - ファイルをドロップした場合、そのファイルが保存されている親フォルダーが自動的に選択されます。
  - Windowsのエクスプローラーからフォルダーをドロップして指定することも可能です（プロジェクト内のフォルダーのみ）。

### ステップ 2: 対象ファイルの選択と除外
- **拡張子フィルター**: `.md` や `.txt` を選択して目的のファイル形式のみを一覧に表示できます。
- **チェックボックス**: 一覧内のファイルをクリックすることで、特定のファイルを変更対象から除外（チェックを外す）できます。
- **全選択**: 「全選択」ボタンで一括オン/オフが可能です。

### ステップ 3: 変換設定とプレビュー確認
- **クイックプリセット**:
  - `[.md → .txt]` ボタン: マークダウン形式のファイルを標準テキスト原稿形式へ一括変換。
  - `[.txt → .md]` ボタン: テキスト原稿をマークダウン形式へ一括変換。
- **変換プレビュー**:
  - 変更前後のファイル名が一覧表示されます。意図通りの名前になっているか確認してください。

### ステップ 4: 実行
- **「〇件の拡張子を変更」** ボタンをクリックします。
- 確認ダイアログが表示されるので「OK」を押すと、安全に一括リネームが実行されます。
- 開いているエディタータブや左側のファイル一覧も自動的に新しいファイル名へ追従更新されます。

---

## 3. 将来の拡張予定（ファイル統合出力）
- 章フォルダー内の複数エピソードを、タイトル見出し付きで1本のテキスト（`.txt`）やPDF等にまとめて出力する機能が次回以降に追加される予定です。
